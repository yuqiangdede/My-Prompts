# 参考图片调色分析

## 用途

从参考图片中提取可用于人工调色的视觉结构。适合快速分析风格方向，不把视觉模型的估算伪装成真实像素统计。

## 输入变量

- `REFERENCE_IMAGE`：参考图片，必填
- `INPUT_COLOR_SPACE`：未知 / sRGB / Rec.709 / Log 等
- `TARGET_USE`：DaVinci Resolve / Premiere / 生图提示词 / 视觉规范
- `MEASUREMENT_TOOLS_AVAILABLE`：是否可访问像素统计工具，默认 false

## 使用说明

需要制作可靠 LUT 时，应使用原始素材、色卡、波形图和实际色彩空间信息，而不是只依赖截图。
