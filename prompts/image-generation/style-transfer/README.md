# 风格转换 Prompt 使用说明

本目录用于分析参考图的色彩与材质结构，或将输入图片转换为指定视觉介质。

## Prompt 对照

| Prompt | 具体能做什么 | 适合场景 |
| --- | --- | --- |
| [01 参考图片调色](01%20参考图片调色.md) | 快速拆解色温、明暗、饱和度和色相关系 | 生图配色、调色沟通、视觉参考整理 |
| [02 参考图片调色](02%20参考图片调色.md) | 输出更接近 DaVinci Resolve 的节点和 LUT 重建方案 | 视频调色、LUT 设计、工程验证 |
| [03 复刻油画](03%20复刻油画.md) | 保留主体和构图，将照片转换为油画材料与笔触效果 | 艺术海报、油画化、概念视觉 |
| [04 复刻老照片](04%20复刻老照片.md) | 按年代、胶片介质和保存状态建立老照片质感 | 历史感海报、档案风格、复古照片 |

## 示例 1：分析参考图调色

### 输入

```text
参考图：雨夜城市街道照片
使用目的：把同样的色彩方向用于港区夜间预警宣传图
需要关注：冷暖分离、黑位、霓虹饱和度和高光压缩
```

### 预期结果

- 阴影偏青蓝，高光偏橙黄。
- 黑位轻微抬升，但保留车辆和人物轮廓。
- 霓虹颜色只在局部保持高饱和。
- 给出视觉估算范围，并说明需要波形图或取样工具才能得到准确数值。

## 示例 2：生成 LUT 重建方案

```text
目标软件：DaVinci Resolve
输入色彩空间：Rec.709 Gamma 2.4
输出：节点顺序、Lift/Gamma/Gain 调整方向、曲线、色相选择器和验证步骤
```

预期输出会给出基础校正、风格节点、肤色保护、局部色相和导出 LUT 的实施顺序。

## 示例 3：油画转换

```text
保留港区雷达站的建筑结构和海岸构图，转换为厚涂油画。
使用可见画布纹理、宽窄结合的笔触和有限调色板，不改变设备数量和位置。
```

## 示例 4：老照片转换

```text
年代：1990 年代中国家庭彩色冲印照片
介质：普通 6 英寸相纸
保存状态：轻微褪色、边角磨损、少量颗粒，不要严重划痕
```

## 使用边界

- 视觉模型不能仅凭压缩参考图生成真正准确的 LUT 数值。
- 需要工程复现时，应结合示波器、直方图、色卡和实际调色软件验证。
- 风格转换应保留主体身份、空间关系和关键对象，避免无依据增删内容。
