# 建筑生图 Prompt 使用说明

本目录用于生成“真实建筑摄影 + 技术分析叠加”的建筑展示图。

## 包含的 Prompt

- [建筑技术分析海报](01%20建筑分析)

## 具体能做什么

- 把指定建筑生成成专业建筑摄影海报。
- 叠加结构分区、材料、功能和观察点等技术信息。
- 适合方案汇报、概念展示、设计分析封面和社交媒体图卡。
- 对未知尺寸使用示意性标注，不伪造真实工程参数。

## 示例

### 输入

```text
建筑名称：滨海低功耗视频监控站
建筑类型：两层小型设备站房
主要材料：清水混凝土、耐候钢、玻璃
环境：港区海岸，阴天，地面潮湿
重点展示：设备舱、维护通道、屋顶相机平台、通风系统
比例：16:9
```

### 预期画面

- 真实的港区建筑摄影效果。
- 主建筑清晰，环境不过度抢镜。
- 使用少量白色技术线、编号和局部剖面框。
- 标注“设备舱”“维护通道”等已知信息。
- 不生成虚假的精确尺寸、施工编号和认证标志。

## 使用方式

1. 打开 [01 建筑分析](01%20建筑分析)。
2. 替换建筑类型、材料、环境、观察重点和画幅。
3. 没有真实参数时，将标注模式设为“概念分析”。
4. 需要准确文字和尺寸时，先生成无字底图，再用 SVG、CAD 或排版软件完成标注。
