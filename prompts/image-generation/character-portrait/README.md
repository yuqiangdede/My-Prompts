# 人物肖像 Prompt 使用说明

本目录用于基于用户提供的成年人物参考图，生成不同用途和风格的人像作品。所有 Prompt 都应优先保持人物身份、脸型、五官比例和年龄特征一致。

## 通用输入示例

```text
参考图：已上传的成年人物正面清晰照片
身份保持：必须保持脸型、眼睛、鼻子、嘴唇和年龄特征一致
允许变化：服装、背景、姿态和灯光
禁止变化：性别呈现、明显年龄变化、脸部结构和肤色身份
输出比例：4:5
```

## 通用使用方式

1. 选择最接近目标效果的 Prompt。
2. 上传一张或多张清晰的成年人物参考图。
3. 替换服装、背景、姿态、画幅和灯光变量。
4. 第一轮只生成身份和构图正确的版本。
5. 后续每次只调整一个变量，例如只改服装或只改灯光，减少人物漂移。

## 常见失败与处理

- **人物变脸**：减少发型、妆容和年龄变化，强化身份锁定。
- **九宫格每格不是同一个人**：固定服装、妆容和基础灯光，只改变表情与机位。
- **文字乱码**：让模型预留排版空间，后期再添加标题。
- **手部异常**：降低复杂手势数量，改用自然放置或局部遮挡。
- **画面像塑料人**：减少“完美皮肤”“超锐利”等词，保留真实皮肤纹理和轻微瑕疵。
