# 视频分镜设计

将主题、脚本、产品演示或业务流程一次性转换为可生成、可剪辑、具备镜头连续性的视频分镜与单镜头提示词。

## 输入

- 视频主题与目标受众
- 总时长和画幅
- 脚本、旁白或业务流程
- 人物、场景和视觉参考
- 视频模型或制作方式
- 必须展示的关键节点

## 执行要求

1. 明确视频目标：解释流程、展示功能、讲故事、营造氛围、演示操作或宣传。
2. 把内容拆成背景、问题、关键动作、变化、结果和收束等叙事节拍。
3. 每个镜头至少定义：编号、时长、景别/机位、主体动作、环境、摄像机运动、光线色彩、衔接、旁白/字幕/音效。
4. 单镜头优先一个主动作和一个镜头运动，明确动作起点与结束状态。
5. 跨镜头锁定人物、服装、道具、场景布局、轴线、界面状态、色彩和光源。
6. 按“镜头目的 → 起始画面 → 主体动作 → 摄像机运动 → 环境变化 → 光线色彩 → 结束状态 → 连续性约束”输出每镜头提示词。
7. 最后检查顺序、跳轴、时长、动作闭环以及字幕/旁白是否与画面重复。

## 输出

- 视频结构
- 分镜表
- 每镜头生成提示词
- 连续性控制表
- 旁白与字幕建议
- 剪辑与转场说明

## 边界

这是一次性分镜 Prompt，不负责真正生成关键帧、视频或验证生成结果。若任务要求生成并检查连续镜头图组，使用 `layered-shot-narrative`；若输入是技术方案并只需要技术汇报 PPT/视频脚本，使用 `prompts/technical-communication/`。
