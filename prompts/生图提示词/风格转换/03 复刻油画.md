# 参考图油画风格转换

## 用途

把照片或场景转换为具有真实油画材料特征的作品，同时保留原图主体、构图和身份，不直接模仿某位在世艺术家的独特风格。

## 输入变量

- `REFERENCE_IMAGE`：待转换图片，必填
- `PAINTING_PERIOD`：古典 / 印象派时期特征 / 现代写实 / 当代厚涂，默认现代写实
- `BRUSHWORK`：细腻平涂 / 可见笔触 / 厚涂 impasto
- `CANVAS`：细纹 / 中纹 / 粗纹
- `COLOR_DIRECTION`：色彩倾向，可空
- `PRESERVE`：必须保持不变的主体、构图或人物特征

## 可复制 Prompt

```text
请将上传图片转换为一幅真实材料感的油画作品。

绘画时期与语言：{{PAINTING_PERIOD|default:现代写实}}
笔触：{{BRUSHWORK|default:可见笔触}}
画布纹理：{{CANVAS|default:中纹}}
色彩方向：{{COLOR_DIRECTION}}
必须保留：{{PRESERVE|default:主体身份、姿态、构图和主要物体关系}}

转换要求：
1. 保留原图的主体数量、人物身份、脸部识别特征、姿态、镜头视角和主要空间关系。
2. 将摄影纹理转换为油彩层次，而不是简单叠加滤镜：
   - 暗部使用透明罩染和较薄颜料
   - 中间调出现可见但受控的笔触方向
   - 高光使用较厚颜料和局部 impasto
   - 边缘同时包含硬边、软边和失焦边，避免所有轮廓同样锐利
3. 笔触方向应服从形体：面部沿肌肉和骨骼转折，衣物沿褶皱，建筑沿结构，天空和水面沿环境运动。
4. 保留自然的明暗体积、材质差异和空气透视，不把所有区域涂成同一质感。
5. 画布纹理在平涂和薄涂区域可见，在厚涂高光处被颜料覆盖。
6. 色彩遵循用户给出的方向；未给出时，从参考图提炼主色、辅助色和点缀色，不随意改变肤色或关键物体颜色。
7. 不复制具体画作、签名、展览标签或某位在世艺术家的独特笔法。可以使用通用艺术语言，例如古典罩染、自然主义写实、松散笔触或厚涂。
8. 不改变人物年龄、性别表达、民族特征、身体比例或服装结构，除非用户明确要求。
9. 不添加文字、画框、博物馆场景、Logo、水印或艺术家签名。

负向约束：
数码油画滤镜、塑料质感、所有边缘同样锐利、重复五官、身份变化、额外人物、错误手指、过度饱和、厚涂覆盖全部画面、画布纹理像噪点、签名、文字、水印。

输出：一张完整油画作品，保持参考图构图，具有真实颜料厚薄、笔触方向和画布纹理。
```

## 使用说明

需要更稳定的结果时，先固定构图和人物，再单独迭代笔触、色彩和颜料厚度，不要一次改变所有变量。
