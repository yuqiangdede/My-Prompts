# 360° 全景图 Prompt 使用说明

本目录用于生成 2:1 等距柱状全景图，并配合 Three.js 制作可交互查看器。

## 包含的 Prompt

- [全景图生成与查看器说明](说明)

## 具体能做什么

- 生成室内、园区、港区、展厅或虚拟场景的 360° 全景底图。
- 约束左右边缘连续、地平线稳定和上下极点自然。
- 生成 Three.js 全景查看器的开发提示词。
- 适合方案演示、场景预览、虚拟巡检和网页交互展示。

## 示例

### 生图输入

```text
场景：港区设备接入网机房
空间：矩形机房，中央通道，两侧机柜
要素：网络机柜、对象存储设备、状态指示灯、顶部桥架、门禁入口
光线：明亮冷白工业照明
风格：真实摄影，整洁但具有正常使用痕迹
输出：2:1 equirectangular panorama
```

### 预期结果

生成一张 2:1 全景图，左右边缘可以连续拼接，摄像机位于中央通道，机柜比例和透视基本一致。

### 查看器开发输入

```text
使用 Three.js 创建一个单文件 HTML 全景查看器：
- 加载 panorama.jpg；
- 鼠标拖动和触摸旋转；
- 滚轮缩放；
- 初始视角朝向门禁入口；
- 提供全屏按钮和加载失败提示。
```

## 使用方式

1. 先用 [说明](说明) 中的全景生图 Prompt 生成图片。
2. 检查左右接缝、地平线和顶部/底部变形。
3. 将合格图片保存为 `panorama.jpg`。
4. 再将查看器 Prompt 交给 Codex 或其他编码模型生成 HTML。
