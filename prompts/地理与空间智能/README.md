# 图片地理位置分析 Prompt 使用说明

本目录用于根据图片中的可见线索，推断可能的国家、地区或城市，并明确证据强弱和不确定性。

## 包含的 Prompt

- [图片地理位置分析](图片地理位置分析.md)

## 具体能做什么

- 分析文字、道路标线、车牌样式、交通规则、建筑和自然环境。
- 给出多个候选区域，而不是无依据地猜一个精确地点。
- 列出支持证据、冲突证据和下一步核验方法。
- 在证据不足时停留在国家级或区域级结论。

不适合用于确定私人住宅、敏感设施或个人实时位置。

## 示例

### 输入图片

一张街景照片，可见右侧通行车辆、蓝底白字路牌、简体中文店铺招牌、蓝色机动车号牌、南方常绿植被和密集骑楼建筑。

### 预期结果

```text
候选 1：华南沿海城市，置信度 0.68
支持证据：简体中文、右侧通行、蓝色号牌、常绿植被、骑楼街区。
反证：没有可识别城市名或唯一地标。

候选 2：中国其他亚热带城市，置信度 0.24

结论粒度：只能判断到华南或亚热带城市，不能确认具体街道。
下一步核验：放大路牌、公交车身文字和店铺电话号码区号。
```

## 使用方式

1. 打开 [图片地理位置分析.md](图片地理位置分析.md)。
2. 填写允许输出的最大粒度，例如国家、省份或城市。
3. 上传清晰原图，不要只提供压缩截图。
4. 将结果视为候选分析，再通过地图、文字搜索或其他图片交叉验证。
