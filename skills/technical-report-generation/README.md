# 技术报告生成 Skill 使用说明

## 这个 Skill 能做什么

把技术方案、系统架构或业务流程整理成适合汇报的报告结构，并进一步生成 PPT 脚本、视频脚本和实现提示。

适合技术方案汇报、项目演示、投标材料、内部评审和产品介绍。

## 具体例子

### 输入

```text
主题：三网架构下的预警录像存储与归档方案
受众：项目经理、存储厂商、开发和测试
关键内容：
- 下级保存原始录像 7 天；
- 人工确认预警后归档到视频专网 90 天；
- 互联网按需摆渡并临时保存 1 天；
- PIR 文件录像与 DE 球回放流处理方式不同。
```

### Skill 会做什么

1. 提炼核心结论、边界、流程和关键参数。
2. 组织成背景、架构、流程、差异、容量、风险和待确认项。
3. 生成适合 PPT 的逐页标题、要点和图示建议。
4. 生成适合视频讲解的旁白、镜头和字幕重点。
5. 给出流程图、架构图或页面效果图的生成提示。

### 最终能得到什么

- 技术报告目录和正文要点。
- PPT 页面脚本。
- 视频分镜与旁白脚本。
- 图表和视觉素材建议。
- 实现、验证和风险清单。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，提供受众、汇报目的、技术材料和篇幅或时长。报告中的参数必须来自输入资料，未确认内容要明确标注。
