# 结构化长文写作 Skill 使用说明

## 这个 Skill 能做什么

把零散资料整理成结构清楚、证据充分、适合提交或发布的长文，覆盖技术方案、分析报告、汇报材料和说明文档。

重点不是堆砌文字，而是先确定读者、结论、证据和结构，再完成初稿与修订。

## 具体例子

### 输入

```text
主题：低功耗设备预警录像存储方案
读者：项目经理、开发和测试
核心结论：误报录像不归档，确认预警后再归档到视频专网保存 90 天。
资料：三网职责、PIR 和 DE 球录像来源、FTP 摆渡、NCG 回放流、并发估算。
篇幅：3000 字以内。
```

### Skill 会做什么

1. 确定文章要回答的关键问题和核心结论。
2. 把资料按背景、方案、流程、差异、容量、风险和待确认项组织。
3. 区分已确认事实、假设和建议。
4. 生成初稿后，检查重复、逻辑跳跃和证据不足。
5. 输出适合评审的正式版本。

### 最终能得到什么

- 结论优先的执行摘要。
- 有层级的正文结构。
- 表格、流程描述和关键参数。
- 风险、边界和待确认事项。
- 可直接提交的最终稿。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，提供读者、目的、核心结论、已有资料和篇幅。资料不足时应保留占位或标记待确认，不能补造数据。
