# 分层镜头叙事 Skill 使用说明

## 这个 Skill 能做什么

将一张影视剧照或场景参考图拆成连续的 A/B/C 起步帧，并根据叙事需要生成 D/E 扩展帧和独立色彩控制卡。

重点是保留镜头空间、人物身份、构图关系和跨帧连续性，而不是简单删除或替换画面元素。

## 具体例子

### 输入

```text
原始剧照：雨夜公交站，一名成年女性独自坐在长椅上。
人物参考：需要替换成用户提供的成年女性形象。
目标：生成适合 15 秒短片的连续画面。
色彩：冷青环境光，暖黄色站牌灯。
```

### Skill 会生成什么

- **A 空间基底帧**：只建立雨夜公交站、道路和长椅空间。
- **B 氛围建立帧**：增加雨水、灯光、车辆虚影和冷暖色关系。
- **C 主体呈现帧**：加入锁定后的成年女性主体，保持原始机位和空间关系。
- **D 叙事关系帧**：例如远处出现即将到站的公交车，仅在它改变人物处境时生成。
- **E 状态变化帧**：例如人物起身看向车辆，仅在存在明确动作变化时生成。
- **色彩控制卡**：单独展示主色、辅助色、亮度和材质控制。

## 最终能得到什么

- 至少 A、B、C 三张连续叙事图。
- 条件满足时生成 D、E。
- 独立色彩控制卡。
- 人物、相机和连续性检查结果。

## 使用方式

阅读 [SKILL.md](SKILL.md)，提供原始剧照、可选配色条和人物参考图。调用“拆解”也会进入图片生成流程。涉及人物替换时，应使用用户提供的参考，不复制原演员身份。
