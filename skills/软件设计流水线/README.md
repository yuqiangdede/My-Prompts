# 软件设计流水线使用说明

## 这个 Skill 能做什么

将一段模糊的 B 端或行业系统需求，按固定 01～10 步整理成需求边界、模块、数据、状态、异常流程、页面规格和最终 UI 生图 Prompt。

它适合复杂业务系统，不适合只改一个按钮文案之类的简单任务。

## 具体例子

### 输入

```text
需求：设计一个统一运维平台。
设备包括低功耗球机、PIR、布控球和双目相机。
需要查看在线状态、执行重启和升级、下载日志，并查看操作结果。
```

### 流水线会怎样处理

1. **问题澄清**：确认设备类型、能力差异、批量操作和失败处理。
2. **问题拆解**：拆成总览、设备列表、详情、任务中心和操作日志。
3. **风险扫描**：检查升级失败、权限、并发和设备能力不一致。
4. **方案决策**：确定统一能力模型和异步任务模式。
5. **模块边界**：划分设备、任务、日志、权限和协议适配模块。
6. **数据与状态**：定义设备状态、任务状态和操作结果。
7. **异常流程**：枚举超时、部分成功、设备离线和重复操作。
8. **页面规格**：输出每页布局、字段、按钮和交互。
9. **一致性校验**：检查页面、流程、权限和状态是否对应。
10. **效果图渲染**：为指定页面输出结构说明和完整 UI 生图 Prompt。

### 第 10 步示例输出

```text
页面：设备运维总览
布局：顶部筛选区和 KPI 卡片，中部设备类型统计与在线趋势，底部异常设备表格。
生图 Prompt：A 16:9 professional B2B device operations dashboard...
```

## 最终能得到什么

- 需求与业务规则。
- 模块和数据对象。
- 状态机与异常流程。
- 页面清单和页面规格。
- 通过 Gate 检查后的 UI Prompt。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，严格按步骤执行。第 9 步未通过时不能进入第 10 步。当前第 10 步生成的是生图 Prompt；需要直接生成并验收图片时，应在下游继续调用图像生成能力。
