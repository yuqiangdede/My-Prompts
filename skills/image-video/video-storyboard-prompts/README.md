# 视频分镜提示词 Skill 使用说明

## 这个 Skill 能做什么

把一段业务说明、故事或宣传主题拆成连续镜头，明确每个镜头的时长、景别、动作、机位、画面内容和转场关系。

适合产品宣传片、技术流程动画、短视频、电影感片段和 AI 视频生成。

## 具体例子

### 输入

```text
主题：低功耗设备预警处置流程
时长：30 秒
镜头数量：6 个
关键流程：设备发现人员 → 智能分析 → 视频专网人工复核 → APP 接收任务 → 现场核验 → 反馈结果
风格：写实科技宣传片，三网边界清晰。
```

### Skill 会做什么

1. 将 30 秒拆成 6 个叙事节拍。
2. 为每个镜头指定场景、主体、动作、景别和时长。
3. 锁定设备外观、人员服装、网络颜色和地图风格。
4. 保证箭头、动作和网络流向与业务流程一致。
5. 为每个镜头生成独立的视频或生图 Prompt。
6. 检查相邻镜头中的人物、设备、时间和空间连续性。

### 最终能得到什么

- 分镜表。
- 每个镜头的画面描述和生成 Prompt。
- 角色、设备和视觉连续性清单。
- 转场方式和节奏建议。
- 可供视频模型逐镜生成的输入。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，提供总时长、平台比例、必须出现的流程和不能改变的主体。镜头越多，越需要先冻结角色、设备和场景参考。
