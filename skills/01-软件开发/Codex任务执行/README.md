# Codex 任务执行 Skill 使用说明

## 这个 Skill 能做什么

把一段自然语言开发需求整理成 Codex 可以直接执行的完整任务，要求它先读仓库、再修改代码、实际运行测试并汇报结果。

适合新增功能、修复 Bug、补测试、调整配置和小范围重构。

## 具体例子

### 输入

```text
项目：Spring Boot 事件管理系统
任务：给事件驳回接口增加驳回原因，旧客户端不传该字段时仍要兼容。
限制：不能修改事件表主键和现有状态枚举；允许新增数据库字段。
验收：接口测试通过，旧请求不报错，新请求校验原因长度。
```

### Skill 会组织出的执行过程

1. 阅读 README、构建文件和事件相关代码。
2. 定位 Controller、DTO、Service、状态流转、数据库模型和测试。
3. 说明最小修改范围后直接实施。
4. 增加字段、兼容逻辑、校验和测试。
5. 执行格式检查、目标测试和构建。
6. 汇报修改文件、验证结果和剩余风险。

### 最终能得到什么

- 一条包含完整背景和约束的 Codex 指令。
- 实际代码修改，而不只是修改建议。
- 可核验的测试和构建结果。
- 清晰的文件变更清单。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，将仓库路径、任务、限制和验收标准填入输入部分。涉及不可逆数据库迁移或生产配置时，需要保留人工确认点。
