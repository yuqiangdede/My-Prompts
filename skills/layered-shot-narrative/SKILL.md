## Skill Contract

- **description**：将影视剧照拆解为连续的分层镜头，并直接交付叙事图片与独立色彩控制卡。
- **input**：原始剧照；可选配色条、人物参考图、主体/关系/动作要求和禁止项。
- **workflow**：逆向拆解 → 处理歧义 → 生成 A → 生成 B → 生成 C → 按叙事价值生成 D/E → 逐帧连续性验收。
- **rules**：遵守 `rules/相机锁定.md`、`rules/人物锁定.md`、`rules/连续性检查.md`；保持双参考生成链；失败只重做当前帧。
- **output**：A/B/C 图片、必要时的 D/E 图片、独立色彩控制卡图片和极简文字说明。
- **examples**：参见本文的荒野轿车拆解示例，以及 `prompts/A 空间基底帧.md` 至 `prompts/E 状态变化帧.md`。

# 分层镜头叙事生成规范

将一张原始剧照改造成可用于短视频的连续图组。**调用即进入“拆解 + 生成”流程：即使用户只说“拆解”“分析”或未明确写“生成图片”，也必须输出图片。**核心原则是：保留原剧照的镜头叙事与空间关系，逐层加入信息；不机械复制演员身份或把画面元素简单删除。

## 输入

每组至少收集：

1. 原始剧照（镜头母版）。
2. 该剧照的配色条（可选，但建议提供）。
3. 人物参考图（可选）。
4. 用户指定的主体、关系层或动作；未指定时先根据剧照提出方案。
5. 禁止项或特别要求。

先确认参考图的角色：

| 参考 | 作用 |
|---|---|
| 原始剧照 | 机位、构图、透视、人物姿态、道具、原始光线逻辑 |
| A 空间基底帧 | 空间布局与空场背景 |
| 配色条 | 色相、明度、冷暖与高光关系；不得出现在画面中 |
| 人物参考图 | 指定人物的身份与面部特征 |
| B/C 等母版帧 | 后续帧的连续性锚点 |

## 硬性约束

- 图像中不得自动加入文字、术语标签或水印。
- 未被叙事需要支持的角色、道具、车辆、动物或特效不得自行新增。
- 不复制原演员的身份。未提供人物参考图时，将原人物替换为新生成、不可识别的成年东亚面容人物；默认保持原人物的性别呈现，除非用户另行指定。
- 提供人物参考图时，仅替换人物身份/面部特征；保持原剧照中对应主体的表情、视线、头部角度、姿态、站位、画面尺寸、服装轮廓关系、手持道具与动作逻辑。

## 帧结构

默认按 `A → B → C → (D) → (E)` 交付连续图组，**最小交付为 A、B、C 三张图片，加一张独立色彩控制卡图片**。D/E 不是默认省略项，必须按下列条件判断：

- **D 必须生成：** 存在一个次主体、群体或环境变量，其出现会改变主主体的处境、目标或观众理解。
- **E 必须生成：** 存在可明确描述、且能延续叙事的动作或状态变化。
- **D/E 可以省略：** 仅在它们没有独立叙事增量时；必须在交付说明中写明省略原因。
- **单张例外：** 仅当用户明确要求“只生成最终成片/单张图”时，才可将叙事帧缩减为单张；色彩控制卡图片仍须交付，且仍须说明该图对应的叙事层级。

不得因用户未指定帧数而只生成最终层。若 C/D 归属存在歧义，先给出最多两个方案并等待用户选择，再开始生成；未选择前不得仅凭偏好生成任一最终帧。

### A｜空间基底帧

**目的：** 提取一张合理成立、色彩完整的基础场景照片：即故事发生前（或主体尚未进入时）这个空间在自然、正常状态下会是什么样。不是把原画面简单删空。

- 锁定：画幅、机位、透视、消失点、场景层级、建筑/场景位置、关键地标关系。
- 移除：剧情主体、人物、动物、车辆、武器、异常物、临时动作与叙事痕迹。
- 重建：合理的基础环境光、正常材质、完整可读的空间与符合空场逻辑的焦点。
- 默认：保留场景在自然条件下应有的真实色彩、材质和明暗；**绝不因为是 A 而自动转为黑白、灰暗或低信息。**
- 景深：优先让已知的空间层级合理可读；原图看不清的区域可保留为自然暗部、雾气或低细节背景，而不是凭空补出具体地形或建筑。
- 不继承：原图为主体服务的浅景深、主体轮廓光、刻意布光、电影化调色，以及仅服务于情绪的天气/特效。
- 保留环境身份：海底、雪山、沙漠、森林雾等若属于空间本身，不作为“戏剧效果”删除。

### B｜氛围建立帧

**目的：** 在 A 的基础场景上，通过布光、调色、影调、天气、反射与镜头光学，把空间转化为原剧照的电影情绪；B 是 C/D/E 的视觉母版。

- **严格继承 A 的所有画面元素、构图、焦点和景深。** B 只允许改变布光、色温、明暗关系、对比度、饱和度、影调、天气质感和反射。
- 禁止在 B 中增加、移除、移动或替换人物、车辆、道具、建筑、地形或其他实体元素；也不得人为增加虚化。
- 直接参考原始剧照和配色控制卡；A 提供空间布局与基础材质，绝不将 A 的自然曝光/色彩误当作 B 的最终风格。
- 若后续需要前景虚化、主体对焦或景深变化，必须在 C 或之后以“主体进入后的摄影动机”发生，而不是提前在 B 发生。
- 无叙事主体，除非某环境元素本身就是场景常态且不承担叙事关系。

### C｜主体呈现帧

**目的：** 让观众明确本段的关注对象。

- 继承 B 的空间、镜头光学、光影和色彩。
- 出现主主体。若两三个人/动物/物体共同构成同一叙事主体、共同完成同一动作或共同面对同一目标，必须同时在 C 出现。
- 替换原剧照主体时，遵循“硬性约束”中的人物替换规则。

### D｜叙事关系帧（可选）

**目的：** 让 C 中主体与另一个对象、群体或环境变量产生关系，从而改变观众对场景的理解。

- 次主体可以是单人、多人、动物群、车流、目标、阻碍、威胁、追兵、猎物或异常物。
- 只有它的出现会改变主主体的处境、目标或关系时，才放入 D。
- 若群体/动物/车流只是场景常态且不承载叙事关系，应属于 A/B 的环境，而非 D。
- D 不等同于“威胁出现”；它是关系、目标或动机被揭示。

### E｜状态变化帧（可选）

**目的：** 给画面一个可感知的后续，让观众产生“然后呢”的期待。

- 在 D 或 C 的基础上，仅改变必要的动作、关系或状态。
- 可用动作：转头、靠近、离开、躲藏、开门、发现、消失、物体启动、灯灭等。
- 保持人物、场景、色彩、道具和镜头连续性；不得无理由重构场景。

## 主体判定

先将原剧照中的元素分成三类：

| 类别 | 放入哪一帧 |
|---|---|
| 场景常态、不可缺少的环境身份 | A/B |
| 观众首先应关注的一个主体或共同主体群 | C |
| 出现后才改变主体处境、目标或理解的次主体/群体 | D |

不要按人物数量判定 C/D，按叙事身份判定。三人小队可一起在 C 出现；街上的人群或草原动物群若承担“关系/目标”才在 D 出现。

## 镜头逆向拆解（先判断故事，再生成）

原剧照通常是叙事信息已经叠加完成的“终态画面”。生成前必须把每个可见元素倒推为它应当出现的层级，不能因为某个物体出现在原图里，就自动把它放入 A/B。

对每个可见元素（人物、车辆、动物、道具、天气、建筑）分别判断：

1. **场景必要性：** 没有它，这个地点还是否成立？成立则它不必进入 A。
2. **叙事增量：** 它出现后，是否让观众重新理解主主体的处境、目标或关系？若是，优先放入 C/D。
3. **因果顺序：** 是谁先让故事开始？谁/什么出现后才产生事件？按因果而非原图中视觉位置排序。
4. **摄影动机：** 某物进入后，是否有理由改变焦点、景深或光线？只有有明确动机时才改变。

### 默认归类

| 元素类型 | 默认层级 | 例外 |
|---|---|---|
| 地形、道路、固定建筑、远山、常态植被 | A | 若其本身被揭示才成为事件，则可后移 |
| 基础自然天气与正常光照 | A | 明显电影化的天气/布光在 B |
| 电影调色、戏剧化布光、影调 | B | B 不改变实体元素与景深 |
| 叙事主角、主车辆、主动物、核心道具 | C | 多个共同主角同在 C |
| 会改变主角处境的第二人、车、群体、动物、道具 | D | 若它只是一开始就存在的场景常态，则回到 A |
| 行为结果、到达、离开、开门、转身、亮灭 | E | 无状态变化则省略 E |

### 反事实测试

为每个候选元素分别问：

```text
如果它暂时不在画面里，A/B 还是一个完整、可信的场景吗？
如果是：它优先作为 C 或 D 的可叙事增量。
如果否：它属于 A 的基础世界。
```

例如荒野轿车剧照有两种合理拆法：

```text
方案 1（人物优先）：
A 空旷荒野道路 → B 电影光影 → C 前景男人 + 背景汽车 → D 车旁两人

方案 2（汽车是事件）：
A 空旷荒野道路 → B 电影光影 → C 前景男人 → D 汽车 + 车旁两人
```

两种方案的差别在于“汽车是否是让故事发生的事件”。无法从单张剧照高置信判断时，先给用户 2 个不超过一句话的拆解方案并等待选择；不要擅自把一个歧义元素锁死在 A。

## 配色控制卡

收到配色条时，从中提取 6–10 个实际需要的核心色，并按用途建立色彩控制卡。推荐角色：

1. 最深阴影
2. 基础暗部
3. 环境主色
4. 空气/天气色
5. 主光或轮廓光
6. 地面/材质反射
7. 主体肤色或主材质色
8. 暖色点缀
9. 最亮高光

对 B–E 使用控制卡。A 使用符合场景自然状态的基础色彩；不强制继承电影配色条，也不得自动转为黑白。提示生成模型：配色条仅用于色彩分级参考，不得将色块、条纹、图案或文字加入画面。

**必须额外生成一张独立色彩控制卡图片。** 该图仅由 6–10 个等宽、纯色、无渐变的矩形色块组成，按上述角色顺序排列；包含本组实际使用的全部核心色。不写任何文字、色值、标签、Logo 或水印，不将色卡嵌入 A–E 任一叙事帧。文字说明中用相同顺序列出色彩角色与色值。

## 双参考生成法

不要使用 `A → B → C → D` 的单链式生成；每一步都会累积构图和色彩漂移。

使用以下锚点：

```text
原始剧照 ─→ A（空间基底）
原始剧照 + A + 配色条 ─→ B（氛围母版）
原始剧照 + B + 人物参考（可选） ─→ C（主体）
原始剧照 + B + C ─→ D（关系，若需要）
B + C + D ─→ E（状态变化，若需要）
```

在每一步明确区分：

- **必须锁定：** 机位、画幅、空间比例、背景关键物位置；C 之后还锁定人物位置、大小、服装轮廓、道具和身份连续性。
- **允许变化：** 当前帧唯一指定的天气、光影、主体、关系或动作。
- **必须移除/禁止：** 原演员身份、未指定元素、文字、水印、未成年角色。

## 执行流程

1. 查看所有参考图，先执行“镜头逆向拆解”；若存在会影响 C/D 顺序的歧义元素，先提出最多 2 个方案并等待用户选择。**在用户选择前，不得生成任何最终交付帧。**
2. 判定 A/B/C/D/E 的实际结构；默认锁定 A、B、C 为必交付帧。若 D 或 E 没有叙事价值，明确省略及原因。
3. 输出本组的简短镜头方案：每帧增加/改变什么、为什么；该步骤只用于规划，不能替代图片交付。
4. 建立色彩控制卡，并将其作为 B–E 的固定约束；同时生成独立色彩控制卡图片。
5. 先生成 A，再在**不改变 A 中任何实体元素与景深**的前提下建立 B。
6. 生成 C，并将 C 作为人物连续性母版。
7. 仅在需要时生成 D/E；一次只改变指定叙事变量。
8. 每次生成后检查连续性；不合格仅重做该帧，绝不把错误继续传递。仅输出文字分析、未生成 A/B/C 图片或未生成色彩控制卡图片，均视为任务未完成。

## 交付

交付 A、B、C 及所有判定为必要的 D/E 纯图片，**以及一张独立色彩控制卡图片**，并附单独的极简文字说明。不得将任何标签写进叙事图片或色彩控制卡图片。除非用户明确要求单张图，否则缺少 A、B、C 或色彩控制卡即视为交付未完成；不允许以纯文字分析代替图片。

文字说明应包含：

- 帧名与叙事作用。
- 本帧相对于上一帧的变化。
- 1–3 个镜头术语标签，例如“深景深”“低调光”“关系构图”“动作延续”。
- 色彩控制卡。

## 验收清单

生成完成后逐帧验证：

- 空间比例、建筑/环境地标、机位与透视是否漂移？
- B–E 是否保持同一色彩控制卡和光线逻辑？
- 是否交付一张包含全部核心色、无文字标签的独立色彩控制卡图片？
- C–E 中的主体是否保持同一成年人身份、站位、尺寸、服装与道具关系？
- 是否出现未指定人物、动物、车辆、物体、文字或水印？
- 是否出现任何未成年角色？
- A 是否作为合理的空间说明镜头成立，而不是残留主体对焦逻辑的删空剧照？

不通过时，定位并只重做对应帧。
