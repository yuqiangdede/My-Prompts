# Python 视觉算法项目复现 Skill 使用说明

## 这个 Skill 能做什么

将一个公开的 Python 视觉项目，从“仓库看起来能运行”推进到“在指定本地环境中可以重复运行、测试自己的数据并记录资源消耗”。

适合目标检测、分类、分割、姿态、跟踪、OCR、人脸、视频理解和三维重建项目。

## 具体例子

### 输入

```text
项目：某个开源目标检测仓库
环境：Windows 11 + WSL2 Ubuntu，RTX 3060 12GB
目标：使用官方权重跑通 Demo，并测试自己的 MP4 视频。
限制：不进行完整训练；可以使用 Docker；最终需要导出 ONNX。
```

### Skill 会做什么

1. 确定复现级别为 L2 官方 Demo、L3 自有数据和部分 L7 部署验证。
2. 核对 Python、CUDA、驱动、PyTorch 和自定义算子兼容关系。
3. 建立隔离环境并记录安装命令。
4. 下载和校验官方权重，跑通官方样例。
5. 测试用户 MP4，记录输入尺寸、显存、FPS 和输出格式。
6. 尝试导出 ONNX，并验证输出是否与原模型基本一致。

### 最终能得到什么

- 可重复执行的环境安装步骤。
- 成功运行的官方和自有数据命令。
- 显存、速度和结果记录。
- 失败原因及修复方法。
- 是否值得继续评测、微调或部署的建议。

## 使用方式

阅读 [SKILL.md](SKILL.md)，提供仓库链接、GPU、系统、Python/CUDA 环境和明确的复现级别。默认先完成官方 Demo 和自有数据推理，不应一开始就投入完整训练。
