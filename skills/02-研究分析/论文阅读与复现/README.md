# 论文阅读与复现 Skill 使用说明

## 这个 Skill 能做什么

把论文、官方代码、配置和实验结果对应起来，判断论文真正做了什么、代码是否完整开源，以及本地环境能否复现。

适合理解新模型、技术选型、运行官方 Demo、验证论文指标和制定降配复现方案。

## 具体例子

### 输入

```text
论文：一个新的三维重建模型
目标：在 RTX 3060 12GB 上跑通官方推理，并判断是否值得做小数据微调。
资料：论文 PDF、GitHub 仓库、官方权重。
关注：输入格式、显存、推理时间、训练数据和与现有方案的差异。
```

### Skill 会做什么

1. 提取研究问题、方法结构、数据集、指标和核心贡献。
2. 阅读方法图、实验表、消融实验和限制。
3. 对照代码中的模型、配置、权重和默认命令。
4. 检查论文主结果是否依赖未公开数据或特殊硬件。
5. 估算本地推理和训练成本。
6. 制定“Demo → 自有样例 → 标准评测 → 小数据微调”的分阶段计划。

### 最终能得到什么

- 一页式论文摘要。
- 论文模块与代码文件对应表。
- 实验可信度分析。
- 本地复现命令和兼容性风险。
- 与论文一致、数值不同、无法复现和未验证事项的分类记录。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，同时提供论文和官方仓库。官方权重推理成功不等于完整训练可复现，两者必须分别说明。
