# 论文阅读与复现

## description

把论文、项目页、代码仓库和实验配置整理成可理解、可验证、可复现的技术结论。重点区分论文声称、代码实际实现和本地环境能否运行。

## input

- 论文 PDF、论文链接或标题
- 官方代码仓库
- 目标任务：理解、选型、复现或改造
- 本地硬件与软件环境
- 关注的指标、模型或实验
- 可接受的复现范围

## workflow

### 01 建立论文地图

提取：

- 研究问题
- 核心贡献
- 方法结构
- 输入输出
- 训练与推理流程
- 数据集和评价指标
- 主要实验结论

### 02 区分贡献类型

判断贡献属于：

- 新模型或新模块
- 新损失函数或训练策略
- 新数据集或评价方法
- 工程优化
- 组合已有方法

避免把论文包装语言直接当成技术创新。

### 03 阅读关键证据

重点核对：

- 方法图和公式
- 消融实验
- 基线选择
- 数据划分
- 参数规模与计算量
- 失败案例和限制
- 附录中的实现细节

### 04 对照代码

检查官方仓库：

1. 论文中的模块是否全部开源。
2. 默认配置是否对应论文主结果。
3. 是否依赖未发布数据、权重或私有服务。
4. 环境文件、CUDA、框架和模型版本是否明确。
5. Issue 中是否存在常见复现失败。

### 05 估算复现成本

根据本地环境评估：

- 显存、内存、磁盘和网络
- 训练时长和推理速度
- 数据下载和预处理
- 编译依赖和算子兼容性
- 可采用的降配方案

### 06 制定复现计划

优先按层级复现：

1. 跑通官方 Demo。
2. 使用官方权重验证一个样例。
3. 在小数据集上复现实验趋势。
4. 再决定是否完整训练和复现论文指标。

### 07 记录差异

把结果分成：

- 与论文一致
- 方向一致但数值不同
- 无法复现
- 因环境或资料缺失未验证

## rules

1. 不只读摘要和 README。
2. 表格、图、公式和关键实验必须回到论文原文核对。
3. 不把官方权重推理成功等同于训练可复现。
4. 不根据显卡型号粗暴判断，需结合精度、分辨率、批次和模型规模。
5. 不编造缺失的训练参数。
6. 论文结论与代码行为不一致时，以实际证据分别说明。

## output

- 一页式论文摘要
- 方法拆解
- 实验可信度分析
- 代码与论文对应关系
- 本地复现可行性
- 分阶段复现步骤
- 风险与缺失信息

## examples

### 视觉模型复现

```text
阅读该论文和官方仓库，目标是在 RTX 3060 12GB 上跑通推理并判断是否值得训练。

输出必须包含：
1. 模型解决的问题和与 YOLO 类方法的差异；
2. 输入尺寸、骨干网络、参数量、显存和主要指标；
3. 论文主结果依赖的训练数据和硬件；
4. 官方仓库中可直接运行的命令、权重和配置；
5. 12GB 显存的推理配置和可能的降配训练方案；
6. 尚未确认的信息和需要实际测试的项目。
```
