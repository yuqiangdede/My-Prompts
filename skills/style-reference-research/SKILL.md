# style-reference-research

## description

检索指定作者或参考作品，提取可验证的视觉风格特征，并将其转换为结构化色彩、构图、光线、材质和生图约束。

## input

- 作者、作品或风格主题。
- 参考图片或作品链接（如有）。
- 目标输出：风格分析、LUT 参数、风格转换 Prompt 或图像生成约束。

## workflow

1. 收集可引用的作品资料和参考图。
2. 区分事实、观察、推断和未确认内容。
3. 提取构图、色彩、光线、材质、笔触、镜头和时代特征。
4. 输出结构化风格参数和适用边界。
5. 生成风格转换 Prompt 或 LUT/色彩分析结果。
6. 检查是否把作者身份、作品内容或未确认事实误写成确定结论。

## rules

- 需要互联网检索时，明确标注资料来源和不确定性。
- 不把风格描述伪装成作品事实。
- 不直接复制受版权保护的具体作品内容。
- 对在世艺术家避免要求“完全复制某人风格”，改写为可观察的视觉特征组合。
- 所有可生成的参数必须可解释、可复用、可验证。

## output

- 资料与事实边界。
- 结构化风格特征。
- 色彩/LUT 建议。
- 风格转换 Prompt。
- 风险、不确定项和后续验证建议。

## examples

输入作者名称和一组作品链接，输出作品资料摘要、构图与色彩特征、可复用的视觉参数，以及不直接复制单一作品的风格转换 Prompt。
