# 图像提示词设计 Skill 使用说明

## 这个 Skill 能做什么

把一个模糊的生图需求整理成主体、场景、构图、镜头、光线、色彩、材质和负向约束明确的图像 Prompt。

适合人物、产品、建筑、UI 概念图、技术宣传图和电影感场景。

## 具体例子

### 输入

```text
需求：生成一张低功耗球机发现人员并上报预警的技术宣传图。
重点：设备接入网、夜间山地、球机、人员目标和无线传输关系。
风格：真实摄影结合少量科技信息叠加。
比例：16:9。
```

### Skill 会做什么

1. 确定主主体是低功耗球机，次主体是远处人员。
2. 建立前景设备、中景山路、背景山体的空间层级。
3. 选择略低机位和中广角镜头，突出设备与环境关系。
4. 使用夜间冷色环境光和设备局部状态灯。
5. 将数据传输只做克制的视觉提示，不生成大段文字。
6. 加入禁止项，例如错误设备结构、多人拥挤、赛博朋克霓虹和乱码标签。

### 最终能得到什么

- 可直接用于图像模型的完整 Prompt。
- 明确的可变参数和固定参数。
- 负向约束和失败修正建议。
- 多轮生成时的单变量调整方式。

## 使用方式

阅读 [SKILL.md](SKILL.md)，提供主体、使用目的、画幅和必须保留的业务关系。需要跨多张图片保持连续性时，应使用“分层镜头叙事”或“视频分镜提示词” Skill。
