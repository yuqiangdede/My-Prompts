# 提示词工程技能库

## description
整理和复用业界常见 Prompt Engineering 方法，将零散提示词转化为可组合 Skill。

## input
- 用户任务目标
- 模型类型（ChatGPT / Claude / Gemini / 图像模型等）
- 输出要求
- 约束条件

## workflow

### 01 任务分类
先判断任务类型：

- 写作创作
- 软件开发
- 技术分析
- 数据分析
- 图片生成
- 学习研究
- 产品设计
- Agent 工作流

### 02 选择提示词模式
根据任务选择对应模板：

#### 角色模式 Role Prompt
定义专家身份、经验、目标和边界。

#### 思维链模式 CoT
要求拆解问题、列出假设、验证方案，再输出结果。

#### ReAct 模式
循环执行：思考 → 行动 → 观察 → 修正。

#### Few Shot 模式
提供输入输出样例，让模型学习格式。

#### Critic 模式
先生成，再自检，再优化。

#### Tree of Thoughts 模式
生成多个方案，对比后选择。

## rules

1. 不直接复制低质量万能提示词。
2. 优先描述目标、约束、验收标准。
3. 复杂任务必须拆分阶段。
4. 输出格式必须明确。
5. 对关键结论要求说明依据。

## output
输出：

- 推荐 Prompt 模板
- 使用说明
- 输入变量
- 示例
- 优化建议

## examples

### 软件架构分析

你是一名资深软件架构师。
请分析以下系统需求：
1. 拆分业务模块
2. 设计数据模型
3. 分析风险
4. 给出多方案比较
5. 输出推荐方案

### 图片生成

你是一名电影摄影指导。
请根据主题生成镜头设计：
- 景别
- 镜头角度
- 光线
- 色彩
- 构图
- 视觉风格
