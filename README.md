# My-Prompts

个人提示词仓库（Prompts），目标是：可检索、可复用、可迭代。

## 快速开始

1. 从索引里选择一个场景对应的提示词文件
2. 按文件内的占位符补全输入（业务背景/目标/约束/输出格式）
3. 直接复制到 LLM 对话里使用（或作为你自己的模板继续改）

## 仓库结构

```
01-软件工程/             # 需求分析、交互渲染、软件设计流水线
02-产品定义/             # 想法→产品定义
03-视觉与多模态理解/     # 图片语义理解
04-安全、合规与风险评估/ # 隐私/合规风险分析
05-地理与空间智能/       # 图片地理定位
06-生图提示词/           # 生成类（人物肖像等）
```

## 推荐工作流：LLM 软件设计流水线（01–10）

如果你做的是 B 端 / 行业系统需求与方案设计，建议从这条“带门禁”的提示词管线开始：

- 入口说明：`01-软件工程/03 软件工程/README.md`
- 按顺序执行：`01 问题澄清与反问` → `02 问题拆解` → `03 需求风险扫描` → … → `10 效果图渲染`

## 约定（建议）

- 一个提示词一个文件；优先用 Markdown（便于版本化与复用）
- 标题/分节尽量稳定：`目标` / `输入` / `约束` / `输出格式` / `示例`
- 文件名：保留当前风格即可（中文 + 编号对检索也友好）
