# 研究与复现

这一分类用于**外部研究、事实核验、论文复现和真实环境项目复现**。

## 目录

- [`research-analysis/`](research-analysis/)
  - `deep-research-fact-checking`：多来源调研、证据分级和事实核验。
  - `paper-reading-reproduction`：论文、代码、实验配置、数据集和硬件条件对照。
  - `python-vision-project-reproduction`：在真实 Python / CUDA / GPU 环境中运行、评测或训练视觉项目。

分类重点是“需要真实资料或真实运行环境”，不是一次性文本总结。
