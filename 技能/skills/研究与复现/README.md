# 研究与复现

本分类管理**外部研究、事实核验、论文复现和真实环境项目复现**相关 Skill。

## 定位

核心判断是“是否需要真实资料或真实运行环境”。只做一次性文本总结，不应放到这里。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`research-analysis/deep-research-fact-checking/`](research-analysis/deep-research-fact-checking/) | 多来源调研、证据分级和事实核验 |
| [`research-analysis/paper-reading-reproduction/`](research-analysis/paper-reading-reproduction/) | 论文、代码、实验配置、数据集和硬件条件对照 |
| [`research-analysis/python-vision-project-reproduction/`](research-analysis/python-vision-project-reproduction/) | 在真实 Python / CUDA / GPU 环境中运行、评测或训练视觉项目 |

## 边界

如果已有可信材料，只需要整理、改写或生成报告，应优先使用对应 Prompt；需要重新检索、核验或实际运行时再使用本分类 Skill。
