# 深度调研与事实核验 Skill 使用说明

## 这个 Skill 能做什么

围绕一个技术、产品或市场问题，拆解子问题，筛选高质量来源，交叉核验关键事实，并输出带证据的结论和建议。

适合技术选型、产品调研、行业现状、设备方案和开源项目比较。

## 具体例子

### 输入

```text
问题：低价人脸门禁设备通常使用专用识别芯片，还是使用通用 SoC 加软件算法？
关注：成本、离线能力、算法授权、典型厂商方案和本地部署可行性。
范围：中国市场，优先近两年的资料。
```

### Skill 会做什么

1. 将问题拆成硬件架构、算法来源、授权模式、价格和部署限制。
2. 优先搜索厂商规格、官方文档、芯片手册和可靠行业资料。
3. 区分公开事实、厂商宣传、社区经验和推断。
4. 对关键结论使用两个以上独立来源核验。
5. 说明证据不足、资料冲突和仍需实测的部分。

### 最终能得到什么

- 问题地图和调研范围。
- 来源分级表。
- 经过核验的关键事实。
- 方案对比与推荐。
- 不确定性、风险和后续验证清单。

## 使用方式

阅读 [SKILL.md](SKILL.md)，提供研究问题、时间范围、地区、预算或技术约束。需要最新事实时必须联网核验，不要仅依赖模型记忆。
