# 产品研发

这一分类用于把**需求、方案、PRD、评审、原型、复盘和端到端产品研发流程**集中在一起。

## 目录

- [`product-development-skills/`](product-development-skills/)：单阶段专项能力。需要只处理需求澄清、分析、方案、PRD、评审、原型或复盘中的某一环节时使用。
- [`product-development-pipeline/`](product-development-pipeline/)：跨阶段总控流水线。需要从模糊需求持续推进到可交付设计结果时使用。

## 分类原则

这里的中文目录只负责人工归类；实际 Skill 名仍以英文叶子目录和 `SKILL.md -> name` 为准。
