# 产品研发

本分类集中管理**需求、方案、PRD、评审、原型、复盘和端到端产品研发流程**相关 Skill。

## 定位

这里既包含可独立调用的单阶段能力，也包含跨多个阶段推进复杂 B 端 / 行业系统的总控流水线。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`product-development-skills/`](product-development-skills/) | 单阶段专项能力：需求澄清、分析、方案、PRD、评审、原型、复盘、知识沉淀 |
| [`product-development-pipeline/`](product-development-pipeline/) | 跨阶段总控流水线：从模糊需求持续推进到可交付设计结果，并在关键节点执行 Gate |

## 边界

- 只处理某一个产品阶段时，优先使用 `product-development-skills` 中的专项 Skill。
- 需要跨多个阶段持续推进并维护 Gate 时，使用 `product-development-pipeline`。
- 中文分类层只负责人工归类；真实 Skill 名仍以英文叶子目录和 `SKILL.md -> name` 为准。
