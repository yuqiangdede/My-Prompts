# Agent 工作流设计 Skill 使用说明

## 这个 Skill 能做什么

根据任务复杂度，在固定串行流程、路由、并行处理、编排器-执行器、评估器-优化器和自主 Agent 之间选择合适结构。

目标不是默认使用多 Agent，而是用最简单、可控、可验证的方式完成任务。

## 具体例子

### 输入

```text
任务：每周收集能在 RTX 3060 12GB 上复现、视觉效果明显的热门 GitHub 项目。
来源：GitHub、YouTube、Bilibili 和技术社区。
输出：项目简介、显卡要求、部署难度、演示效果和推荐等级。
```

### Skill 会设计出的结构

- 调度器：每周触发一次。
- 搜索路由：按 GitHub、视频平台和技术社区分别检索。
- 并行 Worker：独立收集候选项目。
- 去重与归并：按仓库地址、项目名称和论文合并。
- 评估器：根据显存、安装难度、维护状态和可视化效果评分。
- 输出器：生成最终推荐清单。

### 最终能得到什么

- 工作流类型选择及理由。
- 各节点输入、输出和职责。
- 工具权限、失败重试和停止条件。
- 状态保存与去重规则。
- 可测试的成功指标。

## 使用方式

阅读 [SKILL.md](SKILL.md)，提供任务频率、数据来源、工具权限和输出要求。能够用固定脚本解决的步骤，不应交给 Agent 自由决策。
