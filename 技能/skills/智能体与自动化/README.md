# 智能体与自动化

这一分类用于**Agent 工作流设计、Prompt/Skill 评测和自动化编排相关的执行型能力**。

## 目录

- [`agent-automation/`](agent-automation/)
  - `agent-workflow-design`：设计 Chaining、Routing、Parallel、Orchestrator、Evaluator 等 Agent 工作流。
  - `prompt-optimization-evaluation`：建立 Prompt / Skill 测试集、基线、失败归因和回归评测闭环。

仓库级路由器本身属于 `智能体/agents/`，不放在这一 Skill 分类中。
