# 全景生成（`panorama-generation`）

把 360° 等距柱状全景内容和可运行 Three.js 查看器串成完整交付流程。

## 定位

该 Skill 不只生成一张图片，而是负责“全景资产 → 查看器 → 运行与映射验证”的执行闭环。

## 适用场景

- 已有 2:1 全景图，需要制作交互查看器。
- 需要先准备或生成全景资产，再创建查看器。
- 需要检查投影、接缝、方向、交互和本地运行问题。

## 边界

不适合：

- 只需要普通单张图片提示词。
- 只需要一张普通广角照片。

这类任务应使用 [`提示词/prompts/图像生成/`](../../../../提示词/prompts/图像生成/README.md)。
