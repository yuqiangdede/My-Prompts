# 全景生成（`panorama-generation`）

**只需一句场景描述或一张参考图，就自动生成 360° 全景图和可交互的 Three.js 沉浸网页。** 也兼容直接输入已有全景图。

## 三种输入，一种输出

| 输入方式 | 示例 | 处理方式 |
| --- | --- | --- |
| 场景描述 | “黄昏时分的中式庭院，石板路、竹林、池塘” | 文生 360° 全景 → 自动建网页 |
| 普通参考图 | 上传一张客厅照片，说“保持这个装修风格，生成全景网页” | 以照片为视觉锚点补齐其他方向 → 自动建网页 |
| 已有 360° 图片 | `panorama.jpg` / `panorama.png` | 检查全景格式 → 直接建网页 |

**不用自己先生成全景图。** 运行环境有生图能力时，Skill 应实际生成图片，并与网页一起交付；没有生图能力时必须说明无法完整交付，不得把占位图当成成果。

## 最终成品

```text
output/<scene-name>/
├── index.html       # 可交互的 360° 页面
├── panorama.jpg     # 实际生成或提供的全景资产（也可为 .png）
└── README.md        # 说明、启动命令和验收结果
```

功能：鼠标拖动环视、滚轮缩放、手机单指环视/双指缩放、全屏、复位、本地图片切换与拖入替换。默认固定机位，支持环视但**不是可自由走动的真实几何 3D 场景**。

## 直接使用的指令

> 使用 `panorama-generation`：生成一个清晨薄雾中的山顶观景台，远处群山云海、木质栏杆和自然阳光。先自动生成 360° 全景图，再生成适配电脑/手机的 Three.js 页面，直接交付 `index.html` 和全景资产，并做运行检查。

> 使用 `panorama-generation`：把我上传的参考图作为正面视觉和风格参考，合理补足四周、头顶和脚下，制作 360° 全景交互网页。不要让我提前准备全景图。

## 运行

在产物文件夹执行：

```bash
python -m http.server 8000
```

浏览器打开 `http://localhost:8000`。模板默认使用 CDN 加载固定版本 Three.js，首次运行需要可访问互联网；完全离线部署需要把 Three.js 模块一并本地化。

## Skill 内置资源

## 技术限制

单张普通参考图不含背后区域的真实信息，AI 生成的是合理的空间扩展，不是精确测绘或 3D 重建。360° 全景需 **2:1 等距柱状投影（equirectangular）**，不能简单拉伸普通照片充当。
