# 图像与视觉

本分类管理**连续视觉叙事、全景资产和视觉风格研究**相关执行型 Skill。

## 定位

只有当任务涉及真实资产、资料检索、文件生成、查看器、工具链或验证闭环时，才放入本分类。普通单张生图 Prompt 仍属于提示词层。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`layered-shot-narrative/`](layered-shot-narrative/) | 基于参考剧照/场景生成连续分层镜头图组，并检查人物、空间、相机和色彩连续性 |
| [`panorama-generation/`](panorama-generation/) | 生成 360° equirectangular 全景资产，并通过 Three.js 查看器完成运行、映射和交互验证 |
| [`style-reference-research/`](style-reference-research/) | 检索作者/作品资料，提炼可验证的视觉风格特征和生成参数 |

## 边界

普通单张生图、人物肖像、建筑视觉和风格转换 Prompt 位于 [`提示词/prompts/图像生成/`](../../../提示词/prompts/图像生成/README.md)。
