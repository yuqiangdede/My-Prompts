# 软件开发

这一分类用于**真实代码仓库分析、修改、审查、测试和验证**。

## 目录

- [`software-development/`](software-development/)
  - `codex-task-execution`：当前 Codex 直接修改仓库并完成测试/构建验证。
  - `code-review-fix`：审查代码或 PR，定位真实问题并在允许时修复验证。
  - `java-project-architecture-analysis`：分析 Java / Spring 项目的模块、启动入口、调用链、数据、集成和部署。

如果只是生成一份给另一个 Codex 的开发任务书，应使用 `提示词/prompts/software-development/`，不属于这里的执行型 Skill。
