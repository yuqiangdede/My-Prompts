# 软件开发

本分类管理**真实代码仓库分析、修改、审查、测试和验证**相关 Skill。

## 定位

这里的 Skill 必须接触真实仓库或真实执行结果，不负责只生成“建议怎么改”或“给另一个编码 Agent 的任务书”。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`软件开发/codex-task-execution/`](软件开发/codex-task-execution/) | 当前 Codex 直接修改仓库并完成测试/构建验证 |
| [`软件开发/code-review-fix/`](软件开发/code-review-fix/) | 审查代码或 PR，定位真实问题并在允许时修复验证 |
| [`软件开发/java-project-architecture-analysis/`](软件开发/java-project-architecture-analysis/) | 分析 Java / Spring 项目的模块、启动入口、调用链、数据、集成和部署 |

## 边界

如果只是生成一份给另一个 Codex / 编码 Agent 的开发任务书，使用 [`提示词/prompts/软件开发/软件开发/`](../../../提示词/prompts/软件开发/软件开发/README.md)。
