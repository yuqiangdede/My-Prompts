# 提示词优化与评测 Skill 使用说明

## 这个 Skill 能做什么

用真实测试集比较 Prompt 版本，定位失败原因，形成可回归验证的优化过程，而不是根据单次“看起来不错”的输出修改提示词。

适合分类、抽取、写作、生图说明、Agent 指令和结构化输出 Prompt。

## 具体例子

### 输入

```text
Prompt：图片标签
问题：有时把远处模糊建筑误标成医院，并且不同批次标签顺序不稳定。
测试集：100 张街景图片，已有人工标准标签。
目标：主场景准确率提高，错误细分类标签减少，JSON 始终可解析。
```

### Skill 会做什么

1. 建立正常、模糊、遮挡和边界案例测试集。
2. 运行当前 Prompt，记录准确率、格式错误和典型失败。
3. 将失败归因到标签定义、可见度阈值、排序规则或输出约束。
4. 生成少量候选版本，一次只改变关键变量。
5. 在同一测试集上回归比较。
6. 记录版本、指标、提升和退化案例。

### 最终能得到什么

- Prompt 基线指标。
- 失败案例分类。
- 候选版本对比。
- 推荐版本和发布标准。
- 可重复执行的回归测试清单。

## 使用方式

从 [SKILL.md](SKILL.md) 开始，至少提供当前 Prompt、典型失败样例和预期标准。没有测试样例时，只能做结构审查，不能可靠声称效果提升。
