# 风格参考研究 Skill 使用说明

## 这个 Skill 能做什么

对一个视觉作者、作品类型、年代风格或参考图组进行资料研究，提取可复用的构图、色彩、光线、材质和叙事参数，再转换为新的创作 Prompt。

适合建立视觉风格板、影视参考、摄影方向、插画方向和生图风格约束。

## 具体例子

### 输入

```text
研究目标：整理 1990 年代中国家庭彩色冲印照片的视觉特征。
用途：把现代家庭合影转换成可信的年代照片。
关注：相纸、色偏、颗粒、曝光、构图、服装和保存状态。
要求：不要复制某一位具体摄影师的独特作品。
```

### Skill 会做什么

1. 搜集可靠的年代照片、胶片和冲印资料。
2. 区分时代共性、介质特征和个别作品特征。
3. 提取色温、动态范围、颗粒、锐度、闪光灯和构图规律。
4. 将抽象风格转成可以控制的视觉参数。
5. 生成新的风格转换 Prompt 和负向约束。

### 最终能得到什么

- 风格来源与参考清单。
- 色彩、光线、构图、材质和叙事参数表。
- 可直接用于创作的 Prompt。
- 禁止项和容易误用的特征。
- 与原作品保持差异的改编建议。

## 使用方式

阅读 [SKILL.md](SKILL.md)，提供研究对象、使用目的和允许参考的资料范围。优先提取可概括的时代或媒介特征，不应要求精确复制在世作者的独特风格。
