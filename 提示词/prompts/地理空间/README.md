# 地理空间

本分类管理**图片地理位置推断和空间证据分析**相关的一次性 Prompt。

## 定位

适合基于图片中的文字、道路、车牌、建筑、植被等可见线索，输出候选区域、支持证据、反证、不确定性和置信度。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`geospatial-intelligence/`](geospatial-intelligence/) | 图片地理位置分析与候选区域推断 |

## 边界

如果任务升级为“图片 → OCR → Web / 地图检索 → 候选核验 → 排除”的真实执行链，应升级为 Skill，而不是继续扩大单个 Prompt。
