# 结构化长文写作

将资料、观点和目标一次性转化为结构清晰、事实边界明确、适合特定读者的长文。

## 输入

- 写作主题
- 目标读者和发布场景
- 核心观点或预期结论
- 事实、素材和必须引用的来源
- 篇幅、语气和格式
- 禁止出现的内容

## 执行要求

1. 明确读者看完需要理解什么、判断什么或采取什么行动。
2. 把素材区分为已确认事实、作者观点、案例数据、引用材料和待核实信息。
3. 先生成有论证关系的提纲：背景/问题 → 核心判断 → 支撑证据 → 反方或限制 → 建议/结论。
4. 撰写初稿时每段只承担一个主要作用，事实与观点明确区分，重要结论前给依据。
5. 从主题回答度、逻辑跳跃、重复空泛、数据准确性、反例遗漏等方面做一次批评检查。
6. 完成修订与压缩：删掉无证据绝对化表达、同义重复、无关背景和模板套话；补必要定义、过渡、边界和可执行动作。

## 规则

- 不虚构数字、案例、人物和来源。
- 不把未经证实的观点包装为行业共识。
- 不为显得专业而堆术语。
- 引用必须服务论证。
- 如果任务需要真实网络调研和多来源核验，先使用 `deep-research-fact-checking` Skill，再把已核实资料交给本 Prompt。

## 输出

- 写作定位
- 结构化提纲
- 完整文章
- 事实核验清单
- 可选标题与摘要
