# 结构化写作（`writing`）

本目录提供一次性结构化长文本写作 Prompt。

## 定位

适合从已有主题或素材出发，完成“提纲 → 正文 → 事实边界检查 → 修订”的完整写作过程。

## 目录

| Prompt | 说明 |
| --- | --- |
| [`structured-longform-writing.md`](structured-longform-writing.md) | 已有主题/素材 → 提纲、完整长文、事实边界与修订检查 |

## 边界

如果任务需要真实网络调研、多来源事实核验或持续读取外部资料，应先使用 [`研究与复现`](../../../../技能/skills/研究与复现/README.md) Skill，再把确认后的材料交给本 Prompt。
