# 软件开发任务书（`software-development`）

本目录提供面向其他 Codex / 编码 Agent 的一次性开发任务说明 Prompt。

## 定位

适合把零散自然语言开发需求整理成背景、目标、范围、约束、实施要求、验收标准和验证方式完整的任务书。

## 目录

| Prompt | 说明 |
| --- | --- |
| [`codex-task-brief.md`](codex-task-brief.md) | 将开发需求整理成可复制给另一个 Codex / 编码 Agent 的完整任务书 |

## 边界

如果希望**当前 Codex** 直接读取仓库、修改代码并运行测试或构建，应使用 [`codex-task-execution`](../../../../技能/skills/软件开发/software-development/codex-task-execution/README.md) Skill。
