# 软件开发

本分类管理**软件开发任务说明和编码 Agent 输入整理**相关的一次性 Prompt。

## 定位

适合把自然语言需求整理成可以复制给另一个 Codex / 编码 Agent 的完整任务书，不负责直接修改真实仓库。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`software-development/`](software-development/) | 软件开发任务书，目前包含 Codex / 编码 Agent 任务说明模板 |

## 边界

需要当前 Agent 直接读取真实仓库、修改代码、运行测试和验证时，应使用 [`软件开发`](../../../技能/skills/软件开发/README.md) Skill。
