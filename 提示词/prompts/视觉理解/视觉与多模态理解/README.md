# 视觉与多模态理解 Prompt 使用说明

本目录用于对图片进行稳定、结构化的内容识别。

## 包含的 Prompt

- [图片标签](图片标签.md)

## 具体能做什么

- 为街景、园区、监控画面和设备抓拍图生成统一标签。
- 从预设标签中选择主场景和关键设施。
- 控制标签数量、顺序和自定义标签范围。
- 对无效、遮挡、过曝或无法辨认的图片返回异常结果。

适合做图片检索、素材分类、数据集初筛和业务规则前置标注，不适合代替目标检测模型的像素级定位。

## 示例

### 输入图片

一张园区入口图片，画面中可见：园区大门、车辆道闸、保安亭、人行道和停车区域。

### 预期输出

数组模式：

```json
["园区入口","车辆道闸","保安亭","停车场","人行道"]
```

结构化模式：

```json
{
  "valid": true,
  "main_scene": "园区入口",
  "labels": ["园区入口","车辆道闸","保安亭","停车场","人行道"],
  "uncertain": []
}
```

## 使用方式

1. 打开 [图片标签.md](图片标签.md)。
2. 根据项目替换预设标签列表和输出模式。
3. 上传图片并提交完整 Prompt。
4. 需要批量标注时，固定同一版本的标签表和规则，避免不同批次口径漂移。
