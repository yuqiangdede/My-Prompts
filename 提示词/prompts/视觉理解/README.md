# 视觉理解

本分类管理**图片内容理解、标签提取和多模态分析**相关的一次性 Prompt。

## 定位

适合基于输入图片完成对象、场景、属性和标签等结构化识别，不负责持续调用 OCR、网络、地图或其他工具进行外部核验。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`vision-multimodal-understanding/`](vision-multimodal-understanding/) | 图片对象、场景、属性等结构化视觉理解模板 |

## 边界

如果任务需要结合 OCR、网络、地图或其他真实工具链持续核验，应考虑升级为 Skill。
