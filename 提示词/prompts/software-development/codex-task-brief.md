# Codex 任务书生成

把自然语言开发需求一次性整理成可以复制给另一个 Codex / 编码 Agent 的完整任务书。本 Prompt 只负责写任务说明，不在当前仓库执行修改。

## 输入

- 目标仓库或项目目录
- 要实现、修改或修复的任务
- 技术栈与运行环境
- 不允许修改的范围
- 验收标准
- 已知构建/测试命令

## 输出任务书必须包含

1. **目标**：最终必须实现什么。
2. **仓库侦察**：先读 README、构建文件、入口、相关模块、测试与配置，禁止按文件名猜实现。
3. **实施范围**：允许/禁止修改哪些模块，哪些行为必须兼容。
4. **执行要求**：给出简短计划后直接修改，不停在建议阶段；复用现有实现与编码风格。
5. **验证要求**：格式化/静态检查、目标测试、受影响回归、必要构建或启动验证。
6. **失败处理**：验证失败继续定位修复，只有外部阻塞才停止，并给出证据。
7. **安全边界**：删除、迁移、密钥、生产操作或不可逆变更必须设置明确检查点。
8. **最终汇报**：修改文件、解决问题、执行过的验证、未验证项、剩余风险。

## 边界

如果用户希望当前 Codex 直接读取仓库、修改代码并运行验证，不使用本 Prompt，直接使用 `codex-task-execution` Skill。
