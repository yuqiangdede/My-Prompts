# 通用图像生成（`general`）

本目录提供**普通单张或独立图像**的通用 Prompt。

## 定位

适合把模糊画面想法整理成主体、构图、环境、光线、材质、色彩和负向约束明确的可执行生图提示词。

## 目录

| Prompt | 说明 |
| --- | --- |
| [`image-prompt-design.md`](image-prompt-design.md) | 将模糊画面想法整理成结构化生图提示词 |

## 边界

如果任务需要基于影视剧照生成连续 A/B/C/D/E 分层镜头图组，应使用 [`layered-shot-narrative`](../../../../../技能/skills/图像与视觉/layered-shot-narrative/README.md) Skill。
