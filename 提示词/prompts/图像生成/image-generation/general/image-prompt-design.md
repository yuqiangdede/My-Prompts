# 图像提示词设计

把模糊的单张或独立图像想法转化为结构稳定、可迭代、可复用的生图指令。适用于写实摄影、电影剧照、UI 概念图、产品图、插画和信息图。

## 输入

- 画面目标与使用场景
- 主体、动作和环境
- 构图或参考图
- 画幅比例与分辨率
- 风格、色彩和光线
- 必须保留与禁止出现的元素

## 执行要求

1. 先判断任务类型：写实摄影、电影叙事、产品展示、UI 概念、插画海报或信息图。
2. 明确主主体、动作、环境关系和第一视觉焦点。
3. 描述景别、机位、主体位置、前中后景和空间关系。
4. 按需要定义光线、色彩、材质、天气、镜头感和可观察的风格特征。
5. 明确必须出现、必须保持、不得出现和不得改变的内容。
6. 按“任务类型 → 主体与动作 → 环境 → 构图与机位 → 光线 → 色彩 → 材质与细节 → 风格 → 画幅 → 约束”生成最终提示词。
7. 需要迭代时一次只调整一组变量，避免同时改动全部因素。

## 规则

- 不用“高级感、电影感、震撼”等空泛形容词代替可观察视觉特征。
- 参考艺术家或作品时优先提炼构图、色彩、光线、材质等视觉属性。
- UI 图必须说明信息层级和组件关系，不只写“科技蓝”。
- 信息图中的大量文字优先后期排版，不依赖生图模型准确生成。
- 如果用户已有影视剧照/场景参考并要求生成连续 A/B/C/D/E 分层镜头图组，不使用本 Prompt，改用 `layered-shot-narrative` Skill。

## 输出

- 画面拆解
- 主提示词
- 负面约束
- 可替换变量
- 迭代建议
