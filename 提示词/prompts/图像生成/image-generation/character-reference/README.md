# 人物图谱 Prompt 使用说明

本目录用于把已知人物、阵营和关系整理成具有海报设计感的人物关系图。

## 包含的 Prompt

- [人物关系图海报](01%20人物图谱)

## 具体能做什么

- 展示主角、核心人物、次要人物和阵营层级。
- 用颜色、线型和箭头区分合作、敌对、亲属、师徒、指挥等关系。
- 根据题材选择中心型、双核心、阵营分区或谱系型构图。
- 适合小说、影视、游戏设定、项目团队和组织关系展示。

模型不应自行编造角色或关系。人物名称和关系必须由用户提供，或者明确标记为待确认。

## 示例

### 输入

```text
主题：港区船舶搭靠预警项目
核心角色：雷达系统、视频相机、平台、值班人员、无人机、现场执法人员
关系：
- 雷达系统发现目标并引导视频相机
- 视频相机抓拍并上传平台
- 平台向值班人员发出预警
- 值班人员确认后联动无人机
- 现场执法人员接收任务并处置
构图：平台居中，设备在左，人员在右
视觉风格：深色海事科技风
```

### 预期画面

- 平台作为视觉中心。
- 左侧是雷达、相机、无人机设备阵营。
- 右侧是值班和执法人员。
- 箭头清楚体现发现、抓拍、预警、确认和处置关系。
- 画面具备信息图清晰度，同时保持海报感。

## 使用方式

1. 打开 [01 人物图谱](01%20人物图谱)。
2. 提供角色清单、关系和阵营，不要只给作品名称。
3. 人物较多时先控制在 6–12 个核心节点。
4. 文字要求很高时，建议生成无字人物底图，再通过 Mermaid、SVG 或设计软件叠加关系和名称。
