# 艺术黑白肖像组

## 用途

基于成年人物参考图生成 4 张身份一致、姿态不同的编辑类黑白肖像。

## 输入变量

- `REFERENCE_IMAGE`：人物参考图，必填
- `MOOD`：平静 / 克制 / 亲密 / 沉思
- `WARDROBE`：服装，可空
- `BACKGROUND`：默认中灰到暖白渐变
- `ASPECT_RATIO`：默认 4:5

## 可复制 Prompt

```text
请根据上传参考图，生成 4 张同一位成年人物的艺术黑白肖像。四张图保持人物身份、服装和影调系统一致，只改变姿态和视线。

情绪：{{MOOD|default:克制、沉思、自然}}
服装：{{WARDROBE|default:简洁深色上装，无明显品牌}}
背景：{{BACKGROUND|default:从中灰柔和过渡到暖白的极简影棚背景}}
画幅：{{ASPECT_RATIO|default:4:5}}

身份一致性：
- 保留参考人物的脸型、五官比例、眼神、发际线、年龄和可识别特征。
- 不改变人物身份、性别表达、民族特征和身体比例。
- 保留真实皮肤纹理，不做过度磨皮。

统一摄影语言：
- 编辑类黑白摄影，细腻胶片颗粒，丰富灰阶，不使用纯黑吞没面部细节。
- 一束柔和定向主光从侧前方照亮面部，眼睛保留自然眼神光。
- 背景和人物之间有清晰层次，大量负空间，构图安静。
- 85mm 人像镜头感，浅至中等景深，边缘柔和但眼睛清晰。
- 不添加文字、Logo、边框或水印。

四张姿态：
1. 正面轻微侧转，目光看向镜头。
2. 3/4 侧面，目光看向画外。
3. 轻微低头，眼神向下，肩线放松。
4. 头部微微抬起，侧光勾勒脸部轮廓。

四张图不得出现：
重复姿势、不同人物、明显年龄变化、不同发型、不同服装、五官漂移、过度忧郁表演、硬光死阴影、塑料皮肤、错误手指、文字、Logo、水印。
```

## 使用说明

模型不支持一次生成 4 张时，按四个姿态分别生成，并始终使用同一参考图、服装和光线描述。
