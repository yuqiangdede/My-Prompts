# 人物肖像 Prompt 使用说明

本目录用于基于用户提供的成年人物参考图，生成不同用途和风格的人像作品。所有 Prompt 都应优先保持人物身份、脸型、五官比例和年龄特征一致。

## 13 公司主题收藏级史诗叙事海报

### 适用场景

根据上传的人物肖像，以人物巨大侧脸剪影作为海报外轮廓，把公司名称、行业气质、品牌价值和发展愿景转译为剪影内部的完整世界观。画面融合电影海报的叙事纵深与梦幻水彩插画的纸张颗粒质感，适合品牌叙事、企业愿景、创始人肖像或公司主题视觉概念图。

### 输入变量

- `REFERENCE_IMAGE`：人物肖像参考图，必填。
- `COMPANY_NAME`：公司名称，必填，默认 `【公司名称】`。
- `COMPANY_KEYWORDS`：行业、产品、价值观、代表性色彩或品牌关键词，可选。
- `ASPECT_RATIO`：默认 `4:5`，可改为 `2:3` 或 `16:9`。
- `POSTER_TEXT`：可选海报标题；默认不生成文字、Logo 或水印。

### 可复制 Prompt

```text
请根据上传的人物肖像参考图，生成一张以「{{COMPANY_NAME|default:【公司名称】}}」为核心主题的收藏级史诗叙事海报。

参考图：{{REFERENCE_IMAGE}}
公司关键词：{{COMPANY_KEYWORDS|default:请根据公司名称自然推导最契合的行业气质、品牌精神、核心价值与视觉世界观}}
画幅：{{ASPECT_RATIO|default:4:5}}
海报文字：{{POSTER_TEXT|default:不生成文字、Logo 或水印}}

一、人物身份与剪影轮廓
- 以参考人物的巨大侧脸剪影作为整张海报的主外轮廓，侧脸朝向由参考图最自然、最有辨识度的一侧决定。
- 保持上传照片中的脸型、额头、眉骨、眼睛、鼻梁、嘴唇、下颌线、耳朵、发际线、发型轮廓、肤色与年龄特征，五官比例必须与参考图一致。
- 侧脸剪影应完整、稳定、可辨识，轮廓边缘清楚但不僵硬；不要把人物变成另一张脸，不要夸张改变鼻型、下颌、头身比例或性别呈现。
- 人物肖像是叙事世界的容器与视觉锚点，内部画面必须自然生长在剪影范围内，不突破外轮廓，不形成额外人物头部或重复五官。

二、剪影内部的公司世界观
- 将「{{COMPANY_NAME|default:【公司名称】}}」转译成一个完整、连贯、具有史诗感的视觉世界：从公司的行业属性、产品/服务、品牌价值、发展愿景和独特气质中提炼叙事元素。
- 在剪影内部自然融合标志性场景、角色体系、象征符号、关键建筑、代表性生物、核心道具、技术/工艺细节、能量流动与环境层次。
- 让这些元素像从人物记忆、思想和使命中生长出来：前景安排最具识别度的符号与道具，中景展开人物活动和关键场景，远景延伸建筑、地貌、云层、星体或抽象未来空间。
- 内部元素服务于公司主题，不堆砌无关奇观；建立清晰的视觉主次、因果关系和从人物轮廓到世界观核心的阅读路径。
- 如果公司关键词不足，不要虚构具体产品名称、真实Logo或事实性企业信息，而是使用抽象但统一的行业意象、价值观象征和原创世界观。

三、构图与叙事合成
- 采用高级剪影轮廓填充式叙事合成，结合双重曝光联想效果：人物侧脸是外层轮廓，完整公司世界观是内层叙事。
- 构图具有电影海报的纵深、戏剧张力和收藏品级完成度；人物侧脸占据画面主体，内部世界从额头、眼睛、鼻梁、嘴唇、下颌到颈部形成有节奏的空间分区。
- 通过柔和空气透视、轻雾化过渡、局部逆光、体积光和远近层次连接不同场景，让剪影内部看似一个连续世界，而不是生硬拼贴的素材集合。
- 画面边缘保留适度呼吸感，主体轮廓与内部细节之间形成清晰的明度和色彩层级；避免信息塞满、视觉中心分散或剪影外溢。

四、艺术风格与质感
- 融合高级电影海报与梦幻水彩插画风格：电影级构图、叙事光线、史诗尺度、克制而有目的的色彩设计，叠加水彩晕染、透明色层、细腻纸张纹理与手工插画边缘。
- 画面整体高细节、高质感、具有艺术收藏价值；细节清晰但不过度锐化，保留纸张颗粒、颜料渗化和微妙笔触。
- 使用柔和空气透视、轻雾、低饱和高级色调与局部主题色点亮关键建筑、符号或道具；根据公司关键词建立统一色彩语言。
- 既要有真实电影光影的空间可信度，也要有梦幻水彩的诗意和想象力，避免廉价卡通感、塑料质感、模板化企业宣传图或随机奇幻元素。

五、文字与输出控制
- 默认只输出无文字版本，为后期排版预留干净区域；如果明确提供了海报标题，只将其作为克制、清晰、无乱码的排版元素，并保持品牌感。
- 不生成真实公司Logo、虚假品牌标识、随机英文、乱码、无意义字母、日期、网址或水印。
- 输出一张完整的竖版收藏级海报，主体轮廓、内部叙事、光影层次和边缘质感统一完成。

六、硬性排除项
- 完全不出现任何大学、校园、学校、教学楼、教室、操场、宿舍、校徽、校服、学生或教育机构相关元素。
- 不出现与公司主题无关的随机人物群像、重复头部、额外五官、额外肢体、变形手指、漂浮物体或无法解释的拼贴碎片。
- 不改变参考人物的身份、五官比例、脸型、年龄、肤色或发际线，不把侧脸替换成陌生人物。
- 不让内部场景突破人物剪影外轮廓，不生成剪影外的第二个巨大头像，不让多个世界观层相互污染。
- 避免过度磨皮、塑料皮肤、廉价渐变、过曝、死黑、过强锐化、脏乱背景、低清晰度、卡通贴纸感、普通商业广告感。
```

### 使用说明

先上传一张光线均匀、侧脸轮廓或三分之二侧脸清晰的成年人物肖像，再填写公司名称与少量公司关键词。第一轮优先检查人物身份、侧脸轮廓和内部叙事是否统一；第二轮再调整主题色、建筑、象征符号或海报文字。

## 通用输入示例

```text

禁止变化：性别呈现、明显年龄变化、脸部结构和肤色身份
```

## 通用使用方式

1. 选择最接近目标效果的 Prompt。
2. 上传一张或多张清晰的成年人物参考图。
3. 替换服装、背景、姿态、画幅和灯光变量。
4. 第一轮只生成身份和构图正确的版本。
5. 后续每次只调整一个变量，例如只改服装或只改灯光，减少人物漂移。

## 常见失败与处理

- **人物变脸**：减少发型、妆容和年龄变化，强化身份锁定。
- **九宫格每格不是同一个人**：固定服装、妆容和基础灯光，只改变表情与机位。
- **文字乱码**：让模型预留排版空间，后期再添加标题。
