# 雨夜霓虹电影人物照

## 用途

基于成年人物参考图，生成雨后城市高架或街边座椅场景中的写实电影人物照。

## 输入变量

- `REFERENCE_IMAGE`：人物参考图，必填
- `LOCATION`：默认雨后的城市高架桥下座椅
- `OUTFIT`：默认拼色牛仔外套、黄色连帽衫、卡其工装裤、高帮运动鞋
- `TIME`：默认黄昏入夜
- `ASPECT_RATIO`：默认 16:9

## 可复制 Prompt

```text
请根据上传参考图，生成一张同一位成年人物的雨夜城市电影剧照。

地点：{{LOCATION|default:雨后的城市高架桥下或街边公共座椅}}
服装：{{OUTFIT|default:拼色牛仔外套、黄色连帽衫、卡其色工装裤、高帮运动鞋}}
时间：{{TIME|default:黄昏刚入夜}}
画幅：{{ASPECT_RATIO|default:16:9}}

身份一致性：
- 保留参考人物的脸型、五官比例、肤色、年龄、发型轮廓和可识别特征。
- 不改变身份、身体比例、民族特征或性别表达。
- 面部保持真实纹理，不做过度磨皮和偶像化重塑。

场景设计：
1. 人物自然坐在座椅上，采用略低机位但不过度仰拍，腿部和身体比例真实。
2. 地面湿润，有少量积水和自然反射；雨已经停止或只剩轻微细雨。
3. 远处城市灯光形成柔和散景和少量车灯轨迹，不使用密集赛博朋克招牌。
4. 空气中有轻雾，但不能遮住人物面部或服装细节。
5. 前景可有轻微虚化护栏、路面或雨滴，不能遮挡主体。

光线与色彩：
- 暖色路灯作为一侧主光，冷色城市灯作为环境补光，形成明确但自然的冷暖关系。
- 霓虹色只作为局部点缀和地面反射，不把肤色染成蓝紫色。
- 面部曝光准确，眼睛可辨，黑位有细节，高光不过曝。
- 画面具有真实夜景动态范围和电影层次，不使用过度 HDR。

摄影要求：
- 35–50mm 电影镜头感，浅至中等景深。
- 主体清晰，背景散景自然，雨水、布料和地面材质真实。
- 构图有环境叙事，不把人物放成孤立影棚肖像。

负向约束：
人物变脸、赛博朋克文字海洋、肤色被霓虹覆盖、错误腿部比例、额外肢体、积水镜像错误、重复车辆、过度雾化、塑料皮肤、过度锐化、文字、Logo、水印。
```

## 使用说明

夜景写实的重点是可解释的光源和自然反射，而不是堆叠“8K、霓虹、电影感”等形容词。
