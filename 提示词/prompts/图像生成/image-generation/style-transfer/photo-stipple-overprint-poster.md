# 摄影与点刻套印对照海报

适用场景：将上传照片分别制作成 3:4 竖版海报，上半部分保留摄影，下半部分以点刻插画和单色透明套印重构主体。

## 使用方式

上传一张或多张照片后使用以下 Prompt。每张照片独立生成一张海报，上下各占 50%；上半保留照片主体，下半概括和重组代表性视觉结构。

## 可复制 Prompt

```text
请将每张上传照片分别生成一张独立海报，一图一张，禁止拼接。画面为3:4竖版，上下严格1:1分区，各占50%。

上半部分：原始摄影保留原图主体身份、结构、姿态、真实质感、自然光影与原有色彩氛围，仅做轻微高级调色，呈现艺术杂志 / 展览图像质感。可自然扩展环境背景以适配画幅，但不得拉伸、扭曲或改变主体。

下半部分：植物点刻插画 × 单色透明套印只提取最具识别性的主体、轮廓、结构、姿态与叙事关系，重构为极简编辑海报。不要完整复制原图，不要逐物转绘，不保留全部背景；删去无关细节，只保留最有代表性的结构、走势与视觉记忆点，通过概括、裁切、缩放、重组与留白重新表达，使人一眼识别与上方照片的对应关系。即使原图构图普通、背景杂乱、主体偏小，也要主动通过删减、重组、尺度变化与留白，把它“救”成一张成立的作品。

构图采用小主体 + 大留白，主体可偏心、贴边、悬置、纵向排列或局部裁切，形成安静、克制、非对称平衡，宁可删减，不要填满。

视觉核心为同色系半透明套印：多层轮廓形相互穿插、叠印，单层浅、双层更深、三层再加重，交叠区域形成新形状，强调“穿过与叠印”，避免平均叠压。

插画语言以stippling / stipple engraving为核心，用细小点的疏密塑造体积、纹理与明暗，接近复古植物学版画、科学图鉴与铜版画视觉；可辅以极细轮廓线，不要水彩晕染、不要厚重笔触、不要复杂写实背景。
```
