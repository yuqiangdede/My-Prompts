# 图像生成

面向单张图像生成、人物参考、建筑视觉和风格转换等生图 Prompt。

## 当前目录

- [`image-generation/`](image-generation/)：图像生成 Prompt 主目录。
  - `general/`：通用单图提示词设计。
  - `architecture/`：建筑视觉。
  - `character-reference/`：人物参考与图谱。
  - `character-portrait/`：人物肖像、职业照、写真、海报等。
  - `style-transfer/`：调色、油画、老照片等风格转换。

需要生成 360° 全景资产并接入查看器验证时，使用 `技能/skills/图像与视觉/panorama-generation/`。
