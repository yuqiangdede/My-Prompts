# 老照片质感转换

## 用途

把现代照片转换为指定年代和介质的老照片效果，或分析参考老照片的退化特征，用于生图、修图和算法参数设计。

## 输入变量

- `REFERENCE_IMAGE`：待转换图片，必填
- `ERA`：1920s / 1940s / 1960s / 1980s / 1990s 等
- `MEDIUM`：黑白银盐 / 彩色负片 / 即时成像 / 冲印相纸 / 报纸印刷
- `CONDITION`：保存良好 / 轻度老化 / 明显褪色 / 严重损伤
- `PRESERVE`：必须保持的主体与细节
- `OUTPUT_MODE`：生成图提示词 / 参数 JSON，默认生成图提示词

## 可复制 Prompt

```text
请将上传图片转换为具有真实历史介质特征的老照片。

年代：{{ERA|default:1960s}}
介质：{{MEDIUM|default:冲印相纸}}
保存状况：{{CONDITION|default:轻度老化}}
必须保留：{{PRESERVE|default:人物身份、姿态、构图和主要物体}}
输出模式：{{OUTPUT_MODE|default:生成图提示词}}

真实性要求：
1. 先建立年代、胶片或相纸介质与退化程度之间的一致关系，不把所有“老照片效果”机械叠加。
2. 保留人物身份、脸部结构、姿态、服装轮廓、建筑关系和画面内容；老化只作用于成像与物理介质。
3. 根据介质选择合理特征：
   - 黑白银盐：灰阶响应、银盐颗粒、局部密度不均、轻微边缘晕化
   - 彩色负片：染料褪色、色层失衡、暖黄或青绿色偏移、较柔和高光
   - 即时成像：较低动态范围、边框、局部显影不均，但不自动添加品牌标识
   - 冲印相纸：纸张纤维、轻微弯曲、边缘磨损、表面反光
   - 报纸印刷：网点、低分辨率、墨色扩散和纸张泛黄
4. 退化程度必须克制且自洽：
   - 轻度老化：少量颗粒、轻微褪色和边缘磨损
   - 明显褪色：色层偏移、对比下降、局部斑点
   - 严重损伤：折痕、裂纹、霉斑和缺失区域，但仍保持主体可辨
5. 划痕、灰尘、漏光、折痕和霉斑应随机分布且数量有限，不能像统一数字滤镜。
6. 不添加虚假的日期、地点、手写说明、档案编号、报纸标题、人物姓名或摄影师签名。
7. 不改变人物年龄、身份、民族特征和身体结构，不额外增加人物或历史物件。
8. 不把画面整体做成棕褐色。只有与年代和介质相符时才使用 sepia 或暖黄偏色。

当 OUTPUT_MODE=生成图提示词时，直接生成最终图像，并遵守以下负向约束：
现代 HDR、过度锐化、统一噪点、塑料皮肤、过量划痕、重复裂纹、虚假文字、品牌边框、人物变脸、额外人物、水印。

当 OUTPUT_MODE=参数 JSON 时，只输出：
{
  "era": "",
  "medium": "",
  "condition": "",
  "tone_curve": {
    "black_lift_range": [0, 0],
    "contrast_range": [0, 0],
    "highlight_rolloff": "none | mild | strong"
  },
  "color_aging": {
    "temperature_shift": "",
    "tint_shift": "",
    "channel_fade": {"r": 0, "g": 0, "b": 0}
  },
  "grain": {"size": "fine | medium | coarse", "strength_range": [0, 0]},
  "optical_artifacts": [],
  "paper_damage": [],
  "preservation_constraints": [],
  "negative_constraints": []
}

没有像素工具时，参数使用合理范围，不伪造精确测量值。
```

## 使用说明

“老”不是统一滤镜。先确定年代、介质和保存状态，效果通常会比堆叠颗粒、划痕和泛黄更可信。
