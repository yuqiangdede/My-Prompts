# 80-90年代黑白胶片纪实抓拍

## 定位

用于将照片处理为 **1980s–1990s 黑白模拟胶片纪实抓拍** 风格。重点不是精致、锐利或标准构图，而是保留随手抓拍、低保真、私人记忆和旧摄影志（photo zine）的粗粝质感。

## Prompt

```text
raw black-and-white snapshot, 1980s–1990s analog documentary photography, high ISO film, coarse organic film grain, grainy silver gelatin texture, soft focus, slight motion blur, imperfect exposure, deep blacks, blown highlights, muted midtones, low fidelity, accidental framing, tilted composition, off-center subject, candid street photography, roadside snapshot, lo-fi analog photography, unpolished, detached everyday atmosphere, private memory feeling, vintage photo zine aesthetic, no text, no typography, no handwriting, no logo, no watermark, no border
```

## 适用场景

- 街头、市场、路边、旅行途中等日常纪实照片。
- 希望弱化“精修感”，强化偶然抓拍与模拟胶片质感的照片。
- 需要深黑、过曝高光、柔焦、轻微运动模糊和明显银盐颗粒的黑白影像。
- 希望画面具有旧相册、私人记忆或独立摄影志气质的场景。

## 核心视觉特征

- **时代感**：1980s–1990s analog documentary photography。
- **介质感**：high ISO film、coarse organic film grain、silver gelatin texture。
- **成像缺陷**：soft focus、slight motion blur、imperfect exposure、low fidelity。
- **明暗关系**：deep blacks、blown highlights、muted midtones。
- **构图倾向**：accidental framing、tilted composition、off-center subject。
- **情绪**：detached everyday atmosphere、private memory feeling。
- **排除项**：no text、no typography、no handwriting、no logo、no watermark、no border。

## 使用方式

直接使用完整 Prompt；如果用于已有照片的风格转换，可在最前面补充需要严格保留的主体、人物关系、动作和场景信息，再追加本 Prompt 作为整体视觉风格约束。
