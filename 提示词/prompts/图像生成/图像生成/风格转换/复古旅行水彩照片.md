# 复古旅行水彩照片

适用场景：保留原照片主体、场景关系与拍摄视角，将旅行照片转绘为清透、柔和、具有收藏感的复古水彩画面。

## 可复制 Prompt

```text
将照片保留原图主体、场景关系与拍摄视角，转绘为一张具有复古旅行气息的清透水彩风照片。整体呈现自然柔和的手绘质感，带有轻微纸张颗粒、水彩晕染、不规则笔触边缘和淡淡的复古色调，画面清新、舒展，具有旅行记忆与收藏感。

保留原照片中的人物或主体身份、动作、结构、环境关系与主要构图。

画面应是一张完整的复古画风照片本身，而不是平面设计稿。整体色调以柔和暖米白、浅褐、低饱和自然色为主，像旧时旅行画册中的手绘插图。背景与主体自然融合，保留空气感与留白感，但不做卡片化编排。去除原图中的水印、界面元素和无关干扰，使最终效果像一幅优雅、真实、带复古水彩质感的旅行画面。
```
