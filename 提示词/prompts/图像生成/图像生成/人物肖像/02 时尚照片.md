# 高级商业时尚肖像

## 用途

基于成年女性参考图生成简洁、高级、可控的商业时尚写真，重点保持人物身份、姿态逻辑和真实摄影质感。

## 输入变量

- `REFERENCE_IMAGE`：人物参考图，必填
- `OUTFIT`：服装，可空
- `HAIR`：发型，可空
- `MAKEUP`：妆容，可空
- `ACCESSORIES`：配饰，可空
- `BACKGROUND`：背景，可空
- `ASPECT_RATIO`：默认 4:5

## 可复制 Prompt

```text
请为上传照片中的成年女性生成一张高级商业时尚半身肖像。

服装：{{OUTFIT|default:黑色简洁吊带礼服，肩带带少量银色或水钻细节}}
发型：{{HAIR|default:松弛的低盘发，额前保留少量自然碎发}}
妆容：{{MAKEUP|default:清透自然底妆、根根分明的睫毛、橘粉色唇妆}}
配饰：{{ACCESSORIES|default:克制的银色耳饰、手镯和戒指}}
背景：{{BACKGROUND|default:暖灰色无缝影棚背景，黑色大理石或玻璃桌面}}
画幅：{{ASPECT_RATIO|default:4:5}}

身份一致性：
1. 保留参考人物的脸型、五官比例、眼神、肤色、年龄和可识别特征。
2. 不改变人物身份，不进行夸张瘦脸、放大眼睛、改变鼻型或重塑下颌。
3. 妆容和修饰只能增强拍摄效果，不能覆盖真实面部结构。

姿态与构图：
- 半身或腰部以上构图。
- 人物侧身坐下，上身轻微前倾，一只手自然轻托面颊，另一只手臂放在桌面。
- 眼神看向镜头，气质自然、自信、略带思考感，不做僵硬摆拍。
- 手指结构自然，避免手遮挡主要五官。

摄影与光线：
- 85mm 或 100mm 中长焦人像镜头感，浅景深，面部清晰，背景柔和。
- 大型柔光箱从正前方略偏侧打光，配合弱补光，阴影柔和但保留脸部体积。
- 低至中等饱和度、暖灰色调，肤色自然，首饰高光不过曝。
- 画面干净、有呼吸感，所有视觉重点集中在人物。

负向约束：
人物变脸、过度磨皮、塑料皮肤、夸张首饰、服装走光、错误手指、额外手臂、僵硬姿势、强硬阴影、过度锐化、廉价影楼感、文字、Logo、水印。
```

## 使用说明

需要不同版本时，只改姿态、配饰或背景中的一个变量，人物身份和核心光线保持不变。
