# 视频分镜（`video-generation`）

本目录提供一次性视频分镜与镜头提示词模板。

## 定位

适合把故事、产品演示或业务流程拆成镜头、画面、动作、旁白、单镜头提示词和连续性约束。

## 目录

| Prompt | 说明 |
| --- | --- |
| [`storyboard-design.md`](storyboard-design.md) | 故事、产品演示或业务流程 → 通用视频分镜、单镜头提示词与连续性约束 |

## 边界

本目录不负责真正生成视频和验证成片。需要生成连续分层静帧时，使用 [`layered-shot-narrative`](../../../../技能/skills/图像与视觉/layered-shot-narrative/README.md) Skill。
