# 视频生成

本分类管理**故事、产品演示和业务流程的视频分镜**相关 Prompt。

## 定位

适合把输入内容拆成镜头、画面、动作、旁白、节奏和后续生成提示词，不负责真正生成视频成片。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`video-generation/`](video-generation/) | 通用视频分镜、单镜头提示词与连续性约束 |

## 边界

需要真实生成连续静帧并检查人物、场景和相机跨帧一致性时，使用 [`layered-shot-narrative`](../../../技能/skills/图像与视觉/layered-shot-narrative/README.md) Skill。
