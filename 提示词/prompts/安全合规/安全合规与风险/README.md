# 图片安全与隐私 Prompt 使用说明

本目录用于在图片发布、共享或归档前，检查其中可能暴露的隐私和安全信息。

## 包含的 Prompt

- [图片隐私风险分析](图片隐私风险分析.md)

## 具体能做什么

- 识别人脸、证件、车牌、地址、联系方式和账号信息。
- 检查屏幕内容、二维码、工牌、钥匙、门禁卡和内部系统信息。
- 按高、中、低风险说明可利用方式和处理建议。
- 给出“可以发布、处理后发布、不建议发布”的结论。

该 Prompt 只能基于图片中可见的内容判断。没有提供原图文件或元数据时，不能声称读取了 EXIF、GPS 或隐藏图层。

## 示例

### 输入图片

一张员工办公桌照片，画面中包含员工工牌、电脑屏幕上的内部系统、白板上的项目名称，以及快递盒上的手机号。

### 预期结果

```text
总体风险：高

高风险：
- 电脑屏幕显示内部系统地址和客户数据，建议裁剪或整体模糊。
- 快递单显示完整手机号和地址，建议不可逆遮挡。

中风险：
- 工牌包含姓名、公司和编号，建议遮挡姓名与编号。
- 白板包含未公开项目名称，建议局部涂抹。

发布建议：处理全部高风险和中风险区域后再发布。
```

## 使用方式

1. 打开 [图片隐私风险分析.md](图片隐私风险分析.md)。
2. 填写发布渠道、受众和允许保留的信息。
3. 上传原图并执行 Prompt。
4. 根据建议实际打码后，再用处理后的图片复查一次残留风险。
