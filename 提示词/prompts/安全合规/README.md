# 安全合规

本分类管理**内容发布、图片共享等场景的安全、隐私、合规和风险初筛**相关 Prompt。

## 定位

适合根据输入内容做一次性风险分析和发布前检查，不承担系统权限隔离、Agent 信任边界或红队验证。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`safety-compliance-risk/`](safety-compliance-risk/) | 安全、合规与隐私风险分析模板 |

## 边界

需要真实权限控制、Agent 信任边界、危险操作 Gate 或红队测试时，使用 [`安全与质量`](../../../技能/skills/安全与质量/README.md) Skill。
