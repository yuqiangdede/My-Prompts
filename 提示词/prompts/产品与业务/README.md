# 产品与业务

本分类管理**产品定义、业务梳理和产品方案**相关的一次性 Prompt。

## 定位

适合把尚未成型的产品想法整理成用户、场景、MVP、业务闭环、验收标准、风险和路线图草案。

## 目录

| 目录 | 说明 |
| --- | --- |
| [`product-definition/`](product-definition/) | 将模糊产品想法整理成可继续评审和细化的产品方案 |

## 边界

需要真实用户研究、多来源市场调研、跨阶段 Gate 或持续推进到 PRD / 原型时，应转到对应 Skill 或 Agent。
